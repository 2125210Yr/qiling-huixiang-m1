## 制作顺序

1. **模板分析。** 用 Cubism Core 无窗口加载候选 moc3，按原 Idle 运动的起点采样，并渲染实际网格、纹理和绘制顺序。保存可复查的图录、参数与运动清单。重点找坐姿、长发、猫耳/尾巴与腿部绑定；再检查选定候选的参数端点与原待机。
2. **确定复用与新建范围。** 比较源网格与新图轮廓、遮挡、关节位置，区分可复用的层级/曲线/节奏与必须重建的网格/UV/关键形状。固定用户已确认的正面坐姿和双脚前抬，不能为迁就模板改设计。
3. **分层与可动草稿。** 从已确认图准备脸、五官、前后发、猫耳、尾巴、躯干、双臂、裙摆、两腿/脚、桌子与阴影。图像生成仅用于必要的拆分和遮挡补绘，保留原图造型与光泽；先检验小幅悬浮、呼吸、发尾和双腿运动，再扩展表情。单张整图平移或扭曲只能标作构图演示，不能交付为真实绑定。
4. **可编辑交付。** 在独立版本目录生成 cmo3、moc3、纹理、model3 与 motion3，并保留绑定 spec、分层素材、生成/验证脚本。用现有 head-export 文件接口导出，不改全库工具。

## 验收

- 原图与源模型无改动，模板清单覆盖声明的范围，未支持的渲染特性和失败单独报告。

- moc3 通过官方 Core 一致性检查，采样顶点均有限；模型所有纹理与运动引用存在。
- 用本机 Core/导出器验证可运行及可保存数据；未通过 Cubism 5.3 实际打开检查时明确注明验证限制。
