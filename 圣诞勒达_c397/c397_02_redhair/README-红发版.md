# 圣诞勒达红发版

头发已改成接近衣服的暖红色，保留原有发丝、光泽、阴影和透明边缘。原版目录 `../c397_02_moc3` 保持不变。

## 使用

- 在 Cubism Editor 中打开 `model-redhair.cmo3`。已通过编辑器替换纹理，并执行“将纹理集应用于原图”，保存为可继续编辑的工程。
- 在运行环境中加载 `model.model3.json`。请保留本目录的 `model.moc3`、`textures`、`motions` 等相对位置。
- `before-after.png`：左侧原版，右侧红发版。
- `redhair-idle.gif`：待机动作采样预览；`motion-contact.png`：多个姿势对照。

## 修改与验证

仅调整 77 个头发网格对应的纹理颜色，排除了发绳、饰物、宝石和金属珠。贴图仍为 4096 × 4096，透明通道逐字节不变，头发选区以外的像素不变。红色参考经过原像素调色应用，交付纹理没有用生成图重画发丝。

运行版 `model.moc3` 和四个动作文件与原版逐字节一致，因此网格、参数和原有动作数据保持不变。使用官方 Cubism Core 加载了 296 个网格、150 个参数，并检查 135 个动作采样及头发、转头参数极限姿势，计算结果均为有限值；另检查了完整角色及八个姿势的渲染效果。

GIF 是参数曲线采样预览，不等同于完整游戏播放：没有额外模拟部件透明度曲线、游戏事件或物理行为。源目录没有 physics3 文件，本次没有新增物理设置。详细记录见 `recolor-verification.json`。
