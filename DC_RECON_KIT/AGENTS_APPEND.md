# 建议合并进项目 AGENTS.md 的 DC 约束
本文件只是片段。保留原项目指令与安全规则，不直接覆盖。

- 首先阅读 DC_RECON_KIT 与当前 milestone 状态。任务是修复已有 Unity 工程，不是另写泛用 gacha RPG。
- 原作证据分 OFFICIAL/EMPIRICAL/REPORTED/HYPOTHESIS/DESIGN/UNKNOWN；必须带服务区与时间边界。
- 用户负责角色美术、具体技能内容、文案；框架仍需通用效果/目标/状态/表现执行器。
- 先真实基线和测试，再修改；保护未提交改动和用户存档，不擅自升级 Unity/包/渲染管线。
- 主代理持有共享场景/Prefab/meta/包清单及活动 Unity 编辑器写权。子代理按真实目录租约作业，不并发乱改序列化资产。
- 最多4个并发子代理；只读研究/审计先行；禁止递归无限生成代理。
- BattleCore 与 Unity 表现独立；多个时钟独立；编队人数按模式；伤害通道不能合并成通用公式。
- 只有真实运行日志、测试结果、截图/录像与来源对照能支持“通过”。未运行写 NOT_RUN，未测量写 NOT_MEASURED。
- 历史数值候选不代表最终服；不能给未知真实规则添加静默 fallback 后宣称还原。
- 原作素材、私人账户和未知来源代码不自动发布或提交公开仓库。
- 每轮交付路径、版本、真实证据、范围覆盖、未知项。M1通过后等下一阶段目标，不自动无限加功能。
