## E01 — ChargeSpeed / AllAllies

```csharp
var fx = new EffectDef
{
    Id = "g2r14_charge_speed",
    Opcode = EffectOpcodes.ChargeRate, // "charge.rate"
    Kind = EffectKind.ChargeSpeed,
    HasTarget = true,
    Target = TargetRule.AllAllies,
    Side = TargetSide.FromRule, // inherit AllAllies → Ally pool
    Magnitude = 0.25f,          // ChargeSpeedMul += 0.25
    DurationSec = 10f,
    MaxStack = 1,
    SourceTier = 1,
    Group = "g2r14_cs"
};
// EffectCapability.Check(fx).Ok == true
```

**Assert after `Submit(Tap)` on a charged ally:** every living ally `Has(ChargeSpeed)` and `ChargeSpeedMul` rose by `0.25`; every living enemy unchanged. Snapshot enemy `ChargeSpeedMul` / `Status` before Submit.

## E02a — ChargeAmount / AllAllies

```csharp
var fx = new EffectDef
{
    Id = "g2r14_charge_amount",
    Opcode = EffectOpcodes.ChargeAdd, // "charge.add"
    Kind = EffectKind.ChargeAmount,
    HasTarget = true,
    Target = TargetRule.AllAllies,
    Side = TargetSide.FromRule,
    Magnitude = 30f,            // Charge += 30, clamp [0,100]
    DurationSec = 0f,           // instant add; no status required
    MaxStack = 1,
    SourceTier = 1,
    Group = "g2r14_ca"
};
```

**Setup:** set every ally and enemy `Charge` to a known value (e.g. 10) **except** the caster, who needs `Charge=100` to pass `Submit`. After Submit, caster Charge is 0 (skill spend) then +30 from the effect if the caster is in `PickAllies(AllAllies)` (yes). Other allies 10+30. Enemies stay 10.

If QA prefers “caster not in the +30 set”, use `TargetCount`/`LowestHpAlly` — **this fixture requires AllAllies** so all matching allies including caster get the add.
