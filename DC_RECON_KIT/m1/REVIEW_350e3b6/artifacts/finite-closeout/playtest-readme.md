# 契灵回响 · G2 Windows 试玩

将压缩包完整解压到一个文件夹，双击 `开始试玩.cmd` 或 `Resonance.exe`。不需要安装 Unity；请保留程序旁的所有目录和文件。

首页点击「关卡」，选择普通关卡后点击 FIGHT。战斗中点击角色头像释放可用技能，向上拖动头像释放 Slide；出现 Drive 按钮时按提示点击。胜利后 NEXT 进入下一关；PAUSE → HOME 返回首页。

`试玩实录.mp4` 是本包实际运行的连续录像（125.9 秒，无音轨）：默认一级队伍、手动模式、1 倍速，从首页进入首场，释放 Slide，首场胜利后 NEXT 进入第二场；第二场到第二波后暂停返回首页，**没有完成第二场结算**。

这是开发试玩版，仍含占位敌人、教学提示遮挡和未完成的界面表现；不表示《天命之子》还原度验收通过。

程序使用本机存档 `%USERPROFILE%\AppData\LocalLow\Resonance\契灵回响\save.json`，已有进度会继续沿用。本包不包含或覆盖个人存档。验收录像使用启动前生成的默认队伍，录制后已恢复原存档并核对指纹；日常试玩不会自动重置进度。
