2026-09-21。十二件遗物及真实结算账本已接入同一 BattleSim；首领专用行为、战术暂停队列、完整反馈和新回放仍属后续阶段。整体 MVP 尚未完成。

- 每次原生施法完成全部命中和链接效果，再以 A → B → C 的固定顺序处理有限衍生请求。衍生共用扣盾、扣血、死亡路径，不再次暴击／套防御，不触发毒、眩晕延长或递归遗物。
- A 系以敌方原生攻击实际吸盾蓄能，A04 替代基础反击；B 系只复制首次有效单体命中，稳定选择不同副目标；C 系保持出场顺序、不同施法者和声与下一次主动伤害的强奏。
- 不可变结果包含来源、阵营、动作、技能／遗物、目标槽位与代数，区分吸收、生命损失、溢出、有效治疗与过量治疗；聚合使用受检查的 64 位整数。
