# 失声剧院 · 原创远征 v0.1

本说明对应当前已实现规则；最终 Win64 包及本版完整普通实玩仍待 Unity 环境恢复后验证。旧 EXE 不代表本页全部功能。

## 一趟怎么玩

在据点选一个核心出发。固定五人会经过前厅、分岔的一侧、工坊、排练厅、返场回廊、首领门前与首领战，总共五场战斗。战后从候选中选一件临时强化；放弃候选可让存活队员小幅恢复。工坊可以休整或再强化一次，首领门前会恢复全队。

普通攻击自动进行。点敌人确定集火目标；队员充能达到 100 后，点其主要技能释放。守护、治疗和增益技能也要由你决定时机。可用暂停看清首领预告，并为不同队员编排指令：每人一条，替换保持位置，清除后重加放到队尾。恢复时顺序检查充能和目标，无法执行的条目会说明原因并跳过。变速为 1× / 2×。

## 三个方向

- **防护 A：** 敌人打在己方护盾上的实际吸收量转成蓄能。成功主动技能后，消耗完整阈值发动反击；后续强化提高护盾、扩散或过载。观察预告，在敌方群攻前安排守护技能。
- **散射 B：** 普攻和原生单体伤害向其他存活敌人追加伤害。后续强化提高比例、增加目标，并在原生击杀后追加回响。多名敌人存活时能发挥作用。
- **接力 C：** 成功主动技能给下一名未充满的队员充能。后续可由三名不同队员形成和声，再存一份强奏给下一次主动伤害。治疗和护盾不消耗强奏。

卡片说明写明前置关系；不要只看编号。战斗中显示实际蓄能、和声、强奏与最近散射目标。图标亮起对应真实触发；有效伤害、护盾吸收、有效治疗分别计数。

## 首领与重试

白面指挥者会预告「终幕回响」。活着的面具会放大群攻力度，可在读条期间先处理面具，也可以准备护盾和治疗。首领首次降至半血会进入下一阶段并补回已倒下的面具；活面具不会因此回满生命。

首领败北后可原样重试：恢复同一战前生命、配置、遗物和种子；改变集火与技能顺序。战斗中途返回节点或关闭程序，下次从该场战前检查点重新开始，不保存每一帧。

首通解锁等价的「横扫」起始配置，基础属性不额外增加。下一趟重新选核心；临时强化清空，发现记录和永久配置保留。结算复盘中的三个数值事实来自最后一场战斗。
