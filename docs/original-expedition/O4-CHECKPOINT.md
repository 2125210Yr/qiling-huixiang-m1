## 反馈与验证

- 每件遗物分别保存实际触发序号；同一动作触发多件时不会只亮最后一件。刷新画面不制造新触发，重新进入战斗清除表现状态。
- A 显示实际储量和阈值，C 显示不同参与者与已存强奏，B 显示最近真实散射命中的敌方槽位及有效伤害。
- HUD 统计直接来自 ResolutionResult 与 CommandLog。结算三条事实说明最后一战的有效敌伤、实际吸收／生命伤害、治疗与指令结果；一条建议依据实际拒绝或贡献。结算副标题明确最后一战，避免误解为整趟累计。
- 7 项新反馈核心测试 RED 后 GREEN；反馈、回放与队列组合 48/48，通过结果见 `feedback-replay-green.trx`。回放属于 O5，此处只说明组合验证范围。
- 新增 6 项 Unity UI 用例，覆盖真实数值、同时点亮、刷新不续亮、退出清理与文字完整显示。当前已通过本机 Unity 引用的 C# 编译检查（`evidence/o5/compile-02/compile-results.json`），**尚未在 Unity 执行**。
