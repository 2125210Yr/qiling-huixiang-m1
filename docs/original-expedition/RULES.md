# 原创远征 v0.1 运行规则

本文件记录 O2 起的实现约定；实际完成范围以阶段验证记录为准。

- 数学采用冻结输入中的 `JP_LEGACY_EMPIRICAL`，是本模式的原型选择，不宣称原作保真。不改变历史模式的计算与统计合同。
- 每次成功原生 Cast 分配单调递增的 rootActionId，作用域包含所有原生命中、动作内持续伤害与链接效果。持续伤害始终独立标记为 Dot；发生在同一动作内不等于原生直接伤害。
- 原生动作全部完成后，按 A → B → C 顺序执行有限遗物效果。B 内先散射，再检查原生击杀回响；每次衍生重新检查目标，按槽位稳定选取且去重，不消耗战斗随机流。
- C04 在动作开始时冻结是否具有强奏，多段共享该加成；首次合法原生主动伤害确认消费。当前动作形成的新和声只给后续动作。
- 所有已算出的遗物伤害只走现有护盾／生命结算，不再暴击、计算防御、施法、延长眩晕或触发毒与新的遗物。来源携带遗物、root、阵营与目标实例身份。
- 本模式账本从实际结算位置采集，伤害与治疗分列有效量和溢出量；聚合使用 checked 64 位整数。越界、非有限值或触发预算耗尽报告工程 Failed，保留战前检查点，不把错误伪装为普通败北。
- 新增结算与遗物整数转换采用 MidpointRounding.AwayFromZero；比例先在宽数值域计算，再检查范围。复用的 DamageMath 内部舍入保持原分支规则。A 的整数阈值按规格向下取整，储量上限是玩法规则，不是工程静默截断。
- 原生施法在整条动作结束后判定胜负；动作之外的周期伤害在该次扣血完成后判定。Failed 优先，随后首领死亡／敌方全灭，再判断己方全灭。开始后续原生动作前也检查边界，避免首领被持续伤害击败后面具多攻击一次。

## O3 时钟、阶段与战术队列

- 原创 Tick 在暂停／技能政策停顿解除后，先处理状态与持续伤害，再检查稳定边界，随后推进首领／精英调度，再处理己方普通攻击和未被脚本接管的普通敌人。调度只接收这一份已按速度处理的游戏 dt。N7 脚本接管 0／1／2 槽的行动；N4 只接管 0 槽执谱监场，其他敌人沿用原逻辑。
- 同时到达普攻与预告时点时，预告优先。读条期间，包括读条到期但因控制延后的阶段，都不插入普攻；群攻完成后重新安排下一次普攻及预告。动作锁／沉默不会伪造一次已完成的群攻。
- 生命首次达到阶段阈值时，在原生与遗物整条动作的稳定边界标记阶段；读条中的切换效果延至该次群攻完成。只补回固定槽中缺失或死亡的面具，并增加该槽的实例代数；活面具不回复生命。首领死亡或工程 Failed 取消待发意图，保留历史统计。
- 暂停队列仅是本次会话状态，每人一条、替换保序、清除后重新加入排在末尾。单体直接伤害指令记录当时明确选中的敌方槽位和实例代数；未选敌与非单体伤害按原目标规则处理。后续修改全局集火不暗改已有条目。
- 恢复命令先进入日志，再按队列顺序同步逐条 Submit，最后才允许下一 Tick。每条重新校验角色、充能、冷却和目标实例；失败继续处理余下条目，队列消费一次，不等待未来充能。已接受与已拒绝的实际指令均留在命令日志中。
