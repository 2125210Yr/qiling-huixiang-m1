- Date: 2026-08-30
- Status: Draft for player review

## 一句话

**全身厚涂海报当角色本体；头像从全身裁；战斗用半身卡。棋盘和火星是引擎舞台，人不靠骨骼活。**

识别来自「近黑虚空里被打亮的完整人体」，不是像素小队，也不是 Cubism。

---

## 锁定

| 项 | 决定 |
|---|---|
| 媒介 | 商业厚涂插画。细软轮廓，体积靠明暗，不是赛璐璐黑边 |
| 单位 | 头到脚一张海报。腿、鞋、发型必须设计完 |
| 舞台 | 首页/详情：透视棋盘 + 虚空 + 火星（`VisualTokens` 地板）。列表：45° 菱格马赛克 |
| 光 | **角色是灯**。暖主光打在人身上，棋盘吃角色的金/橙反射。禁止把棋盘烤进立绘（焰刃 V3 烤了棋盘，下一张出透明底） |
| 动 | 本阶段角色静帧。允许一张闭眼图做眨眼。禁止网格拧、纸娃娃、像素呼吸 |
| 战斗 | 半身/头像卡 + HUD/特效。场上不要像素小人打厚涂 Boss |
| IP | 自有 25 人（焰刃…低语引）。禁止原作名字、服装剪影、Logo、pck 图 |

## 禁止

- Live2D / Spine / 3D / 像素风混进角色层
- 圆框胸像当 Home 主角
- 每人一种画风（日漫、厚涂、Q 版混排）
- 立绘带完整透视棋盘背景（与引擎地板打架）
- 为「动」牺牲脸（拧网格、错位闭眼）

## 三套图，同一张原画

每名契灵只画 **一张全身**，另外两套从它来，不要另起一张脸。

| 用途 | 文件 | 尺寸 | 比例 | 出现 |
|---|---|---|---|---|
| 全身 | `presenter.png` | **1024×1536** | 2:3 | 首页、详情 |
| 闭眼（可选） | `presenter_blink.png` | 同全身 | 2:3 | 仅换眼，构图锁死 |
| 头像 | `portrait.png` | **1024×1024** | 1:1 | 契灵格、编队、图录 |
| 战斗卡 | 先用 `portrait.png` | 1024×1024 | 1:1 | 战场五人；以后可加 768×1152 半身 |

磁盘：

```
client/Assets/Resources/Art/Characters/C00X/
  presenter.png
  presenter_blink.png   # 可缺，缺则不眨眼
  portrait.png
art/characters/C00X-名字/     # 源文件、v3 备份，不进包也行
```

Unity：`alphaIsTransparency = 1`，`nPOTScale = None`，`wrap = Clamp`。全身 **RGBA 透明底**。

## 模板：焰刃 C001

以 `presenter-v3.png` 为构图宪法，后来的人对齐它，不对齐像素人。

**全身**

- 人物约占画幅高度 78–88%，头距顶 ≥ 6%，脚距底 ≥ 8%（马尾可以出框，脸不行）
- 3/4 站姿或轻浮空（脚尖离地可以，要读得懂重心）
- 剪影：头 + 躯干 + 一条主发型 + 一件手持或袖摆。远看仍能认出职业
- 脸：五官清晰，眼睛是高光点。不要把脸埋进头发或特效
- 服装：暗底时装 + 一点高饱和点缀（焰刃 = 黑皮衣 + 绛红内里）。元素色做点缀，不要整身纯色块
- 背景：透明或纯黑虚空。火星/光晕可以极少，棋盘交给引擎

**头像**

- 从全身 **同一张脸** 放大，构图：头顶到锁骨/领口
- 眼睛在画面中心略上
- 禁止另画一张「更二次元」的脸

焰刃现有 `portrait.png` 合格：同一张脸、厚涂皮肤、黑红发、暗领。其余 24 人按这个裁法，不要用像素替身。

## 舞台怎么叠

| 层 | 谁画 | 说明 |
|---|---|---|
| 虚空 | 引擎 `BgVoid #000000` | 清屏色 |
| 棋盘 | 引擎 `FloorDark #101012` / `FloorLight #2A2934` | 透视，只在首页/详情 |
| 火星 | 引擎 Embers | 少、慢 |
| 角色 | `presenter.png` | FitInParent，头脚进框 |
| UI | 贴边：底栏、右上设定、左下名字 | 不要大板块盖脸 |

列表页不用棋盘，用菱格马赛克 `#121212`，角色只出头像卡。

## 元素与职业（色 + 剪影，不是换画风）

色板用现成 token，衣服上 **点到为止**：

| 元素 | Hex | 点缀 |
|---|---|---|
| 火 | `#D02018` | 内衬、宝石、发尾 |
| 水 | `#1C8DE1` | 饰品、刃光、眼 |
| 木 | `#2F900A` | 纹样、坠饰 |
| 光 | `#D0B33D` | 金线、耳环 |
| 暗 | `#814B98` | 内衬、阴影边 |

职业靠 **道具和站姿**，不靠换画派：

| 职业 | 剪影 |
|---|---|
| 攻击 | 刃/弓在身前或身侧，重心前倾 |
| 防御 | 盾或厚外套，重心沉、占地大 |
| 干扰 | 咒物、散开的袖/发，手势外指 |
| 治疗 | 灯、杖、药具，手在中线 |
| 辅助 | 乐器、镜、旗、无主武器 |

## 没图时

禁止再让像素人和焰刃并排。缺资源用 **统一色板剪影**：

- 圆角卡，底 = 元素色 35% 叠黑
- 中心一个浅色人体剪影（同一套 5 职业剪影即可）
- 白字名字 + 元素·职业
- 有 `portrait.png` 立刻替换剪影，不改卡尺寸

## 动效（角色之外）

| 地方 | 动 |
|---|---|
| 角色 | 静。可选 2.5–4s 换闭眼 0.1s |
| 点按/上滑/驱动 | 数字、刀光、色闪、震屏（已有 CombatFeel） |
| Fever | 全屏粉/金闪 + 字 |
| 棋盘火星 | 已有，保持稀 |

不要给 24 个没立绘的人做呼吸缩放（现在的 `PresenterIdle` 像素晃，上线前关掉）。

先默认队 5 张全身+头像，再补齐 25。默认队已是五色五职：

| 序 | Id | 名 | 元素·职 | 备注 |
|---|---|---|---|---|

| 2 | C007 | 白昼守望 | 光·防御 | 盾、白金、沉 |
| 3 | C010 | 影缚者 | 暗·干扰 | 影线、手势 |
| 4 | C003 | 潮汐祭司 | 水·治疗 | 灯/杖、潮色点缀 |
| 5 | C005 | 森语引路者 | 木·辅助 | 枝/镜、引路 |

然后按火→水→木→光→暗补完格子。敌人 E001–E005 / EBOSS 用更脏、更剪影的半身，不要和契灵同一套时装密度。

## 验收（每一张）

1. 缩小到 128px 宽仍能认出是谁（发型+衣服色）
2. 放在纯黑上不脏、不缺脚、不缺头顶
3. 头像和全身是同一张脸
4. 棋盘是引擎的，图里没有第二套地板
5. 和焰刃并排：同一套厚涂，不是另一家工作室

---

## 和代码的接点（有图再改，本规格先锁）

- 首页/详情：继续 `AddFittedStandee` + 透明 `presenter.png`
- 契灵/编队/图录：`portrait.png`，没有则色板剪影，**不要 PixelStandIn**
- 战斗五人：同头像卡
- `PresenterIdle` 仅开发占位，有立绘后不再挂

Live2D 以后如果做，只在这套静帧上切，不重画脸。
