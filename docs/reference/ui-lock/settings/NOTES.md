# 设定锁定包（纪念版）

对照 `天命之子数据/视觉图鉴.html` §03 模态。

## 1. 要对的图
**ref.png** = 纪念版 `050_settings.png`（1200×2670）。设定模态叠在 Home 上。  
不要用 `001_home` 或 `../_not-memorial/operational_home.png`（jp_new_02）当设定 ref。  
**`052_home_after_settings.png` 是关掉设定后的 Home，不是设定本身。** 已收入 `../home/`，本夹不锁。

## 2. 这是什么
从 Home **右上六边形（齿轮）** 打开的设定模态。关掉（确认或 X）后回 Home。不是独立页，不是汉堡菜单。

## 3. 空间关系（锁）
- **75% 黑罩**（`overlay.dim` `#000` @ 75%），角色仍隐约可见。禁止不透明全屏挡脸。
- 圆角暗面板约 **80–90% 宽**，`panel.fill` `#121010`（约 85–90% 透）。金线细框 `#8E6D3E` / `gold.metal` `#CF9403`。
- **虚线分隔**（音效 / 画面 / 资料设定 / 其他资讯）。列表行 + 开关 / 滑条，不是嵌套卡片。
- **确认胶囊脱离面板、居中浮在下方。** 柠檬黄 `#FDDA00` → `#FFB200`，深描边。不是焊在面板脚里。
- **X 在面板顶右。**
- **无六页签。** 纪念版 050 底栏仍透出 Home 六页签，因为设定叠在 Home 上；我们的设定模态不要画六页签。右缘六边形是 Home 底，不要改成汉堡。

## 4. 我们的 loc
标题 **设定**。确认 **确认**。不要汉堡菜单。

## 5. 学空间，不抄发行文案
不要把原作设定行里的具体商标 / 账号绑定 / 开场动画 / 图示授权文案当发行文本。  
学空间：**列表行 + 开关 + 下方确认**。滑条、ON/OFF、分类虚线、浮在面板下的确认胶囊。

## 6. 不要
不透明全屏挡脸 · 汉堡菜单 · 六页签画进设定 · 确认焊进面板 · 用 052 / 001 / jp_new_02 当设定 ref。
