## 1. 先说清楚：三站都不是官方 loc

三份 GameKee 都是**简体中文玩家 wiki**，按服务器分栏，不是 ja / ko 官网。

- 目录、词条标题、技能说明几乎全是中文。
- `wiki_tree_dcj.json` / `wiki_tree_destinychild.json` 顶层节点是中文栏目名（`新手入门`、`五星天子图鉴`、`图鉴资料`…）。节点字段：`id`, `name`, `pid`, `content_id`, `child`, `icon`, `type`, `status`。
- `dcj/catalog_index.csv` 里假名几乎没有（抽到 `贪婪 プロケル`、`狂三のrd` 两处）。韩服目录里**零条谚文**。
- `cross_index.csv` 的 `name` / `title` 也是中文。日服栏经常 `name=绰号`、`title=稍长的中文称号`（例：`相机` / `完美的波坦`，`光豹子` / `诺托斯`，`木高达` / `亚巴顿`）。

所以：**有「日服/韩服 wiki」≠ 有日文/韩文本地化。** 三站提供的是同一套中文玩家用语的三个切片，外加各服图鉴覆盖差。

官方 loc 在客户端 `locale.pck`（韩服私服包扫到谚文词条约 20470、CJK 约 81058），**这次没有解包成表**。韩服 wiki「66.汉化」写了文件分工，见 §4。

## 5. 完整游戏 loc-pack 需要什么

目标四语：`zh-Hans` / `ja` / `ko` / `en`。键用内部 id（`M5-000`、技能槽、buff id），不要用中文名当主键。

### 5.1 必须（能开一局）

| 桶 | 例子 | 现状 |
|---|---|---|
| 角色显示名 | 称号+本名，按皮肤/属性分条 | zh-Hans 5★/4★ 可用；ja/ko/en **空** |
| 角色绰号（检索） | 相机、光狗、宋丹丹 | 日服 `name` 列一大堆；不要当正式名 |
| 技能槽标签 | 自动 / 轻点 / 上滑 / 驱动 / 队长 | 可用中英两套；日韩未表 |
| 技能**名** | Slide 切镜上那一行 | zh 缺；en/ko 只有录像样本 |
| 技能**说明** | 图鉴长句 | zh 5★/4★ 有，但是韩式直译（§6）；3★ 以下空 |
| 点火差分说明 | tap/slide/drive ignited | zh 约 166 人 |
| Buff/Debuff 名+一句 | `攻击力↑` | zh 93 条 |
| HUD 锁字 | SHOWTIME / PERFECT / AUTO | 有英文观察稿；产品已决定用「开演 / 驱动 / 狂热 / 警告」**自撰**，不进原作英文招牌 |
| 主界面/养成 | 设置、图鉴、装备、召唤 | 韩服对照图；无四语表 |
| 属性/职业 | 火水木光暗；五职业 | zh 有；ko 汉字词表有；en 是 Fire/Water/Wood/Light/Dark |

### 5.2 应该有（图鉴像游戏）

魂卡名+特效、人偶名+技能、装备/附魔名、章节/关卡、活动模式名（Ragna:Break ≠ Raid ≠ 诸神强袭）、CV、皮肤名。

现状：魂卡/人偶中文名有；装备 wiki「几乎只有图没有名字」；模式名三服互译混乱。

### 5.3 完整包才要（本仓库不做）

剧情/语音字幕、邮件、教程、错误码、商店（发行禁）、LiveOps。官方在 `scenario` + 其余 def/tab。

### 5.4 不该进 loc-pack

- 私服韩文名、裸体面板、技能数字 id
- GameKee 绰号当 `name_zh`
- 韩式直译技能句当「官方简中」
- Resonance 的 `catalog.json`（`冰刃`/`直斩` 是自撰 twin，不是 DC 译名）

## 6. 对表陷阱（重点：CN wiki 上的韩语 calque）

国际服 `dc` 技能栏很多是**韩文技能句的逐词汉化**，再夹英文槽位名。`gallery_html.py` 已写明要丢掉「GameKee title-padding / **韩文直译前缀**」。

### 6.1 句式 calque（出现在 `汇总表.csv` 技能列）

| 中文 wiki 写法 | 韩文源 | 问题 | 若要人话 |
|---|---|---|---|
| **永远套用**所有光属性盟友 | 영원히 적용 | 「套用」是软件词；队长技永久光环 | 永久生效 / 始终 |
| **skill充能**加速 | 스킬 충전 | 中英混写；大小写乱 | 技能槽加速 |
| **skill充能忠** / 充能中 | 충전 **중** | 「中」被打成「忠」 | 技能槽充能中 |
| 对 1 名暗属性敌人**优先** | 우선 | 像「优先处理」，其实是索敌优先级 | 优先选中 / 以暗属性敌人为目标 |
| **完全充能** | 완전 충전 | 可保留，但和「满槽」混用 | 满槽时 |
| **弱化减益无效** | 약화 디버프 무효 | 双重否定叠词 | 弱化类减益免疫 |
| **减益效果时间缩短** | 디버프 시간 감소 | 通，但繁简/词序跟着韩文 | 减益持续− |
| **起始效果** | 시작 효과 | 开战触发 | 开场 |
| **忍耐** N 秒 M 次 | 인내 | 不像游戏术语 | 受伤忍耐 / 刚体次数 |
| **生命连接** | 생명 연결 | 可留 | 生命链接 |
| **双刃剑** | 양날의 검 | 可留（自伤换增伤） | 同 |
| 1 名盟友（**高攻击力**） | 공격력 높은 | 像「高攻玩家」 | 攻击最高的一名盟友 |
| （**PVP**、攻击型） | 모드 게이트 | 中英混 | 竞技场 |
| 2 **回合**内（点火后） | 턴 | 这游戏战斗是实时秒，点火文却写回合 | 需对照版本，不要当秒 |

领导技常把两句粘在一起、中间没标点：`skill充能加速：永远套用所有木属性盟友+20%skill充能加速：永远套用…（PVP）+20%`。

### 6.2 名字：绰号 / 正式名 / 三站互撞

`cross_index.csv` 日服 `name` 是玩家外号，`title` 才接近图鉴称号：

| `name`（绰号） | `title` | 别对成另一人 |
|---|---|---|
| 相机 | 完美的波坦 |  |

| 双马尾、白兔子、蒙眼、花奶、婚纱、复活奶、白斩鸡、宋丹丹、埃及猫、小苹果、木奶、木高达、美国佬、背包、猪皇 | 各不相同 | 日服图鉴主键是绰号 |
| 狄刻 | 狄刻（奶光） | 职业外号进了 title |
| 夏露露 | 查理 | 中文名 ≠ 西文名 |
| 薇薇安 | 茶杯 |  |

### 6.4 简繁、OCR、拉丁残留

- 国际服技能窗常见 **繁体**（`永遠套用`、`時間縮減`），GameKee 和纪念版 OCR 是简体。`match_cross.py` 用 `zhconv` 再比。
- OCR：缘→绿、姐比→妲比、反擎→反击、自睛妃、傅教的黛娜。
- 拉丁：`SNOW MIKU` 是联动官方名，不是乱码；`我可是完全不知道·228` 才是坏行。

### 6.5 覆盖差造成的假对应

- 日服 wiki **没有 4★ 页** → 不能拿日服五星皮去对四星同名核。
- 韩服 5★ 312 vs 纪念版 282：多的是韩服后期，对不上不要硬配。
- 私服 SQL 637 韩文名：**计数和面板指纹可以核，字符串不能相等。**
