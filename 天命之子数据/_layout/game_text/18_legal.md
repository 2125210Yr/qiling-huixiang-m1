# 18 发行：法律 / 账号 / 入核 / 商店页

研究手册用。进客户端前先定文案，不要临上架再写。  
产品名走发行名 **契灵回响**；内部名 Resonance。  
本文件只写 **clean-room 中文**。禁止原作角色名、原作 Logo、原作技能句、原作商店 SKU。

锁（与 `docs/PROJECT_STATUS.md`、`docs/reference/offline-pack-1.1/04-mvp-gap-and-bans.md` 对齐）：

- 发行包不进原作 APK / pck / jar / SQL / 纪念版立绘。
- **无后端、无账号服、无真金 IAP、无联网抽卡、无 PvP 对战。**
- 存档只写本机 `save.json`。商店页是核尘兑换，不是支付。
- 25 名自造契灵；玩法是 clean-room 重建，不是官方授权。
- 非营利、研究向。国内应用商店无版号则 **不上架**，只做私下研究分发 / 海外或独立平台。

现工程缺口（写进客户端前要接）：Boot 只有 2 秒金标题，没有语言、年龄、隐私、条款、版权确认。设定里没有法律入口。包名仍是 `com.resonance.verticalslice`，版本 `0.1.0`。

## 2. 年龄分级

目标：**主动降风险**（`画风整理.md`）。不学原作暴露剪影。幻想战斗保留。无真实货币、无用户生成内容、无社交。

| 区 | 建议 | 问卷要点 |
|---|---|---|
| 中国适龄提示 | **12+** | 幻想战斗、非写实伤害。若立绘仍偏暴露，升 **16+**。 |
| IARC / Google Play | Teen **12+**（Fantasy Violence） | 无血腥特写、无裸露、无烟草酒精、无赌博、无用户交流。 |
| PEGI | 12 | Violence (fantasy)。 |
| ESRB | T 10+ 或 T，看立绘 | Fantasy Violence。无 Suggestive Themes 才保得住 10+。 |
| 国内商店 | 不上架则不必申版号 | 研究包只私下分发。 |

首次年龄门：

```
本游戏含幻想战斗。
建议 12 岁及以上游玩。

我已年满 12 岁          [进入]
我未满 12 岁            [退出]

未满 12 岁：

```
感谢你的诚实。请在监护人陪同下再来。
```

关于页一行：

```
适龄提示 12+  ·  幻想战斗  ·  无真实交易
```

商店内容警告（短）：

```
含 stylized 战斗。无裸露、无真实暴力、无内购。

若发行立绘达不到「无暴露」：年龄门与商店一律改 **16+**，不要硬标 12+。
