## 5. 技能文法：人偶 vs 天子

天子 `skills.csv`：每人 AUTO/TAP/SLIDE/DRIVE/LEADER；TAP/SLIDE/DRIVE 几乎都先打伤害 `对目标造成 MIN（MAX）伤害N次`，再接 `效果名：时长，筛选目标 数值（成长）`；队长 `永远套用`；另有点火 `text_ignited`。

人偶是给已装备天子 **附加同槽技能**（攻略原话：额外技能，走正常 Buff 冲突）。文法两套并存：

**A. 效果名抬头（2023 词条，近天子 wiki）**

`秘愈（100%概率）：10秒内，2名盟友（低HP）+400`

`Skill充能加速-100%几率：永远套用所有火属性盟友+7.5%`

**B. 叙述句（2022 大批量）**

`对攻击目标中的2名随机敌人造成失明（减少攻击命中率30%），持续12秒`

`赋予自身挑衅（发动概率：80%），持续12秒`

对照要点：

| | 天子 | 人偶（本表） |
|---|---|---|
| AUTO | 有，固定伤害句 | **无**（SQL 首位亦无 1） |
| 槽 | 五槽写满 | 按稀有度 1–3 槽；无 AUTO |
| 伤害 | TAP/SLIDE/DRIVE 必有 MIN/MAX | 多数无面板伤害；有则是「加成伤害 / 无视防御 / 固定伤害 / DoT」 |
| 成长 | `403（2589）`、点火文 | 表内只有 LV1 摊平值；LV70 空 |
| 队长 | `永远套用` + 常驻数 | 同模板，幅度更小（史诗常 +7.5%） |
| 时长 | TAP ~8–10s，SLIDE ~12–16s，DRIVE ~16–20s | 同档；队长无时长 |
| 筛选 | 属性、职业、低HP、高攻击力、PVP | 同；职业用 攻击型/干扰型/治愈型 |
| 概率 | 写在效果名后 | 「有 x% 的机率/几率/概率」「发动机率: 75%」常与正文粘连 |

时长/目标/「永远套用」与天子同一套词。不要把人偶句当成天子 TAP 的伤害骨架来抄。

## 6. 缺口

### 6.1 成长曲线

- 纪念版卡面：**LV 1/10** + **TIER**（技能清单同行）。
- 词条模板：LV1 / **LV70**（套天子技能表，不是 1/10）。
- CSV：`lv1` 全空；`lv70` 只有标签；无 MIN/MAX、无 `level_equation_*`。
- SQL：`puppet_skill` 有 `value_1`、`duration_*`、`buff_*_prob`、`level_equation_*`（数值比天子技能表更「公式」）。离线包 BAN 把人偶当战斗规格挖。

本表 **不能** 还原 1→10 或 1→70 曲线。

### 6.2 入手 / 来源

CSV 无获取列。JSON「推荐搭配」亦空。已知系统（不在本表）：星云、人偶券、diorama 68、商店/邮件（BAN）。无法按行标来源。

### 6.3 风味 / flavor

纪念版人偶 modal：**名字 + 稀有 + 属性 + lv 1/10 + flavor + 四槽加成行**。本表与 `puppets.json` 均无 flavor、无 SD 立绘说明。天子 flavor 在纪念版详情，人偶这边零条。

### 6.4 其它文本债

- 缺 12（对纪念版）/ 33（对 SQL）条词条。
- 效果2 被摊平丢掉。
- 错字/粘连（样例，未改 CSV）：`阍属性`→暗；`Slide Slill`；`晕昡`；`治疗只身`；`建议屏障`；`球鞋斗土`；`防御力2%` 缺符号；`Skill量表充能速度10%` 缺 ±；`启动机率: 75%` 与后句无分隔。
- 名：仅 `未知的桑纳托斯人偶` 带「人偶」后缀；图鑑格子常显示 `…人偶`。短名 `A.I` / `丽莎` / `妲比` / `莫娜` / `猶大` 与天子重名风险。
- 无职业、无 HP/ATK、无 diorama 套装文。

---

## 7. 结论

`人偶.csv` 是 **220 条 wiki 技能摘录**，不是完整人偶主数据。身份列（名/稀有）满；属性差 2；技能四槽按稀有度故意留空（稀有以下每行只 1 条）；成长、入手、flavor 在本表为 **零**。文法可当「附加 TAP/SLIDE/DRIVE/LEADER」的句模，不能当天子技能或 SQL `puppet_skill` 的替代。
