## 5. 特效语法（`special` 153 条）

词条格子只有这一句战斗文，没有故事。纪念版对应栏名 **特殊追加能力**。

### 5.1 骨架

```
[装备时 / 准备时] ， [场合门] ， [属性/职业门] ， [触发] [效果] （普：A[/B] ； 闪：C[/D]）
```

触发常见：装备时（常驻）、发动攻击时、被攻击时 / 遭受攻击时、使用 SS 时、击败敌人、暴击时。

数值括号三种，越旧越残：

1. `（普：15%/；闪：17%/）` — 新卡；满破位空，只留斜杠。
2. `9（10）%` / `15（16）%` — 普（闪）写在同一对括号。例：`多事的跨年晚会`、`妲比的特别派对时间`。
3. `（普：10%/X；闪：12%/X）` 或 `（普：300/X；闪：325/X）` — 旧卡；`X` / `XX` 是 wiki 没填满破。

4★/3★ 常不写普/闪，只给一对成长：`增加中毒伤害（50/250）`。`梦幻队伍` 少右括号：`攻击敌人恢复HP（700/1500`。

### 5.2 场合套话（例）

| 门 | 例 name | special 摘 |
|---|---|---|
| 通用 | 炎热夏日 | 全部能力增加（普：250/350），被攻击时，恢复(普：190/210）HP |
| PVP | 坐在阳伞下 | 在PVP中装备时，攻击时回复300/325HP，有15/17%的几率移除增益 |
| 5人巨型boss | 社长，打得好！ | 在5人巨型boss中装备时，skill量表充能速度增加（普：10%/；闪：11%/） |
| 20人巨型boss | 平静的绵羊牧场 | 在20人巨型boss时，装备时增加减益回避率（普：13%/；闪：15%/） |
| wb / 世界王 | 花之乐园 | 对世界王时，装备时增加减益回避率（普：13%/；闪：15%/） |
| rb / 副本 | 安息吧 | 在副本装备时，增加减益效果回避率（普：13%/；闪：16%/） |
| pve | 如炎般光辉 | 装备时，在PVE中持续伤害增加（普：250/；闪：300/） |

| 地铁 | 海中约会 | 在地下迷宫中增加中毒伤害（普：500/750；闪：515/765） |

### 5.3 效果词库（产品可仿结构，勿抄原句）

- 面板：全部能力增加、最大 HP / 攻击 / 防御、最终敏捷、最终暴击、最终防御。
- 输出：TS / SS / DS、暴击 skill、弱点 skill、无视防御、持续伤害、中毒/流血/诅咒/分解、乱舞之刃。
- 续航：攻击时回血、受击回血、击败回血、回复量、持续回复、吸血/吸收（「只有具有吸血或吸收技能的 child 可用」）。
- 控场：减益命中/回避、减益持续缩/增、时间系减益、弱化减益、移除增益、无视挑衅。
- 异常回避：眩晕/晕眩、睡眠、失明、沉默、石化、冰冻、流血、中毒、禁止回复。
- 量表：skill 量表充能速度 / 充能量、受击时量表增加。

用词不统一：skill / SKILL / 技能；晕眩 vs 眩晕；减益中率（缺「命」）；普卡特效里「闪」位常空。

## 6. 缺 flavor 名、缺套装

### 6.1 flavor / 故事：**0 / 156**

CSV 无 flavor 列。国服/韩服词条都是表 + 卡面，无介绍段。纪念版检视有一句 flavor（装备卡例：「夜晚街道的鬥士像海市蜃樓一樣在2:00 AM出現」挂在魂卡槽上），**从未拆进本表**。

名字本身是场景标题，不是故事正文。三站同卡不同译，不能当唯一主键：

| 国服 CSV | 韩服图鉴 |
|---|---|
| 炎热夏日 | 一个炎热的夏日 |
| 虎猎狐 | 抓虎的狐狸 |
| 莉莎的撞球技术 | 丽莎的台球实力是？ |
| 我们一起度过的冬天 | （同名） |

### 6.2 套装加成：**0 / 156**

魂卡 **没有** 2/4 件套。一天子一张。`soul_carta_option` 是突破档的 option 行，不是套装。装备套装在武器/防具/饰品，不在这张表。培养帖「联动绝版一览」只是联动分组，不是套装效果。

### 6.3 名字像素材、不像战斗卡

除三张「休息处」外，短名/联动角色名当卡名：`綾音`、`环`、`露娜`、`女天狗`、`Nightmare`、`Hero`、`心`、`海咲`、`S.O.W`、`S.T.F.`。这些是标题，仍无 flavor 句。
