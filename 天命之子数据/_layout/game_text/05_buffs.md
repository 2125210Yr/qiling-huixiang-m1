# 05 Buff / Debuff 词条盘点

来源优先级：

1. `天命之子数据/buffs.csv`（UTF-8 BOM，**93 数据行** + 表头 `kind,name,effect`）
2. `天命之子数据/总看板.html` `#buffs` + `#buff-json`（同 93 条，另加 `kind` 中文 / `group`）
3. GameKee 国服词条 **content_id 20902** `Buff&Debuff`（`docs/reference/gamekee/pages/20902.json`，图鉴资料 / BUFF）
4. 拆表副本 `docs/reference/gamekee/tables/buffs.csv`（与本表同 93）
5. 解析残本 `docs/reference/gamekee/parsed/buffs.json`（约 52 条，**两格粘成一条**，不可当名录）
6. HUD 样本：`战斗动效.html` 录像帧（Regen / Vampirism / ATK Stack / Debuff Blast）
7. 技能原文：`汇总表.csv`、`人偶.csv`、`魂之歌牌.csv`（补百分比、时长、词条外名字）

**未改 CSV / HTML / wiki JSON。** 本文件只盘点。

日服 `dcj`、韩服 `destinychild` 的 `catalog_index.csv` **没有**对应 BUFF 词条；机制详解链 `dc.gamekee.com/22566.html` **未进**抓取包。

## 1. 覆盖口径

| 口径 | n | 备注 |

看板 KPI：**增益 58 · 减益 35**。这是 `#buff-json` 的中文 `kind`，**不是** wiki 的 Buff/Debuff 分段，也不是 CSV 英文字段 `kind`。

| 来源 | buff/增益 | debuff/减益 | 怎么来的 |
|---|---:|---:|---|

| CSV `kind` | **82** | **11** | `build_tables.parse_buffs()` 直到「流血」才翻成 debuff |

## 4. 缺什么：百分比 / 时长 / 叠加 / 图标 / HUD 短名

词条页作者原话：

> 注：仅仅只是取游戏中技能效果的字面描述  
> （2）游戏中点暂停（或图鉴）可以看见人物的BUFF图标，点BUFF图标会出现说明。  
> 关于Buff的叠加与覆盖，我没有详细研究。

看板也写：**多数只有名字和一句效果，没有具体百分比。**

### 4.1 百分比 / 数值

名录里**自带数字**的只有这些：

| 名称 | 名录里的数 | 技能原文里常见的补数（不在 CSV） |
|---|---|---|
| 适应痛苦 | 每失 2%HP → +4% 防，顶 160%；「只加本效果给的防」 | 基底防常写 +850（1328）一类 |
| 升华痛苦 | 每失 2%HP → +60% 攻，顶 2400%；「只加本效果给的攻」 | 基底攻常写 +200 |
| 专注 | 100% 命中、100% 暴击 | — |
| 狂暴 | 结束 100% 晕 5s | 攻 +40% / +50% / +90% / +110% / +120%；持续 20s 等 |
| 呐喊 | **只写「百分比」「最多 3 层」**，没有每层 % | — |
| 猛毒 | 回复 −50%；不可缩短/延长 | DOT 量在技能里 |
| 猛毒增幅 | DOT +300；回复 −30% | — |
| 水球 | 被打 2 次耗尽回数 | 「同数值固伤」——技能才给数值 |
| 晕眩 | 挨打 +1s，顶 5s | 基础时长 4s / 5s 等 |
| 灼烧 | 热伤每 2s | Skill 防下降量、热伤量在技能里 |

其余 **83** 条效果是「增加 / 减少 / 强化 / 一部分 / 一定量」，**没有系数**。系数在天子 TAP/SS/DS 文本（如 `攻击力+40（80.1）%`、`屏障+1800（2249）`、`流血每2秒140（603）`），不在本表。

### 4.2 时长单位

名录几乎不写持续时间。出现过的单位：

| 写法 | 出现处 | 含义 |
|---|---|---|
| `5s` / `5秒` | 狂暴后摇晕、晕眩上限 | 秒 |
| `1s` | 晕眩挨打延长 | 秒 |
| `每2s` | 灼烧热伤 | 跳伤间隔 |
| 「一定时间」 | 回复、冷却时间减少/增加 | 未定量 |
| 「持续时间内」 | 激怒 | 未定量 |
| 「效果时间内」 | 晕眩、石化 | 未定量 |
| 「回数」 | 水球 2 次、石化「一定次数」 | 次数，不是秒 |

技能原文才有可抄的时长分布（`_stats.json` skill_token）：持续 **16秒** 194、**12秒** 142、**20秒** 123、**14秒** 116、**10秒** 112、**2回合** 89、**8秒** 68、**3回合** 26、**5秒** 26。点火后常把秒改成回合。

名录**没有** `duration_type`（Timed / 回合 / 次数 / 永久队长）。队长技「永远套用」不进这 93 条。

### 4.3 叠加规则（名录里写了的）

| 规则 | 覆盖 |
|---|---|
| 呐喊最多 3 层 | 仅呐喊 |
| 流血可叠加；中毒不可叠加 | 仅这两条 DOT |
| Skill充能↑ 可与「Skill回复加速」叠 | 与 Skill充能加速 互文 |
| Skill充能↓ 可与充能减速叠 | 同上 |
| 猛毒、分解：不可缩短也不可延长 | 两条 |
| 减益屏障会把屏障顶掉 | 减益屏障效果 + wiki 页脚「雪内裤」注 |
| 诱惑：新增益无效，无法移除（除特定技能） | 诱惑 |
| 耐心 / 忍耐 **共用一格图标** | 20902 rowspan |
| TS强化 / TS强化Ⅱ 共用图标 | 同上 |
| SS强化 / SS强化Ⅱ 共用图标 | 同上 |
| 减益效果无效 / 免疫 共用图标 | 同上 |

名录**没写**的全局规则（来自公式页 / 看板，不是 20902 正文）：

- **同一图标：Drive > Slide > Tap**；同级后写覆盖前写（`parsed/formulas.md` Overlay、看板 `#buffs` caption）
- 社区：同类多数不可无限叠，DOT / 持续回复有例外（`deep-research-report.md`）
- 20902 页脚承认没研究清楚，链到未抓取的「Buff机制详解」

`parsed/buffs.json` 的 `stack_group` 只是把 `name` 复制一遍，**没有**真实分组。

### 4.4 图标文件名

20902 每行有一张 wiki CDN `.jpg`（`cdnimg01/02.gamekee.com/M00/…`），**没有**游戏内资源名（没有 `buff_atk_up` 这类 key）。

- 共享图标 4 对 → wiki 94 行大约 **90** 张独立图；CSV 93 行（无冰冻）大约 **89** 张。
- 这些 jpg **没有**拷进 `天命之子数据/icons/`（那里是天子脸）。

## 6. 完整游戏还缺的战斗文案

名录只够做**暂停图鉴**：名字 + 一句说明。战场还要三套句子，本仓库 **0 条**原文。

### 6.1 战斗日志（建议字段，无官方句）

每条状态至少：

| 事件 | 需要的句 | 现状 |
|---|---|---|
| 命中施加 | `{施术} 对 {目标} 赋予「{名}」` / 敌人侧对调 | 无 |
| 未命中 | 减益被回避 / 未命中 | 无；只有「减益效果回避率↑↓」词条 |
| 跳伤 / 跳疗 | `{目标} 因「流血」受到 {n}` / 「回复」+{n} | 无；数字层是白伤/绿十字，不是 log |
| 层数变化 | 「呐喊」2 → 3 | 无 |
| 到期 | 「{名}」结束 | 无 |
| 被驱散 | 「{名}」被移除 | 无 |
| 爆发 | 诅咒结束额外伤、雪球炸弹结算、增益爆发 | 无句；录像只有 `Debuff Blast` 飘字 |

### 6.2 施加 / 解除 Toast

录像：技能打中队友后 **0.4s** 内，头像顶弹出英文短词（Regen / Vampirism / ATK Stack），不是中文全名，也没有「已解除」条。

需要而没有的：

- 93（+冰冻）条的 **HUD 短标签**（中/英/韩，≤12 字）
- 施加色（绿增益 / 红减益 / 青叠层）
- 解除是淡出图标还是再弹一次（未见解除 toast）
- 多状态同时上时的排队（未见）

### 6.3 免疫 / 无效 / 抵抗句

名录只描述**状态本身**，不描述**对撞时屏幕上写什么**：

| 对撞 | 名录相关条 | 缺的句子 |
|---|---|---|
| 免疫挡住新减益 | 免疫、减益效果无效、沉默无效化、专注（抗失明/抗暴击减益） | 「免疫」「无效」是否飘字未知 |
| 诱惑期间上新 Buff | 诱惑 | 是吞掉还是弹「无法获得增益」未知 |
| 致命回复把治疗打成伤 | 致命回复 | 治疗数字变红？无样本 |
| 禁止回复 | 禁止回复 | 治疗 0 还是不出数字 |
| 忍耐挡伤害 | 忍耐、直击（无视忍耐） | 挡下时有无「MISS / 无效」 |
| 石化/晕眩中被打 | 石化次数、晕眩延 1s | 无「延长」提示 |
| 狂暴无敌 | 狂暴 | 敌技能是「免疫」还是不出伤 |

减益命中公式在研究报告里是重建值，**不是**官方 log 文案。

### 6.4 EffectDef 还要有、名录没有的列

对照 `DATA_MODEL_FROM_REFERENCE.md` 的 `Effect → StackGroup → Priority → Duration → TargetRule → DispelRule`：
