# 09 · 游戏开发文本 — 装备 / 材料 / 点火 / 温泉 / 还魂

盘点 **ITEM / EQUIPMENT / MATERIAL** 文案。结论先说：**纪念版装备图鉴几乎是空的**；韩服 SQL 有行数和槽位语法，没有可发行的中文名；GameKee 装备页几乎只有图。完整游戏要自己写一套名字、稀有度、槽位、词缀、来源、强化确认。

对照：`总看板.html#gear` / `#modes` · `战斗与数值.html`「游戏里有、这里没有」· `docs/reference/offline-pack-1.1/` · `_extract/offline_pack_crosscheck.md`。

**BAN：** 不要把 SQL 韩文 `item.name`、`view_idx`、4406 行 `equation`/`logic`、私服 GM 武器写进发行包。本文列 **需要哪些文案槽**，不是抄原作名录。

点火规则（intro，可当 **系统文案骨架**，数字不要当发行表）：

- 入口：夜世界「赫菲斯托斯的锻造屋」（账号 Lv.7）
- 四种核心：**增幅攻击力 / 防御力 / 敏捷度 / 暴击**
- 打造：该类型核心材料 ×99 + **原生 5★ Child** + 15 万金币（进化/强化型不能当材料；用掉的 Child 不返还）
- 材料不够：50 水晶买 1 个
- 卖出：核心 7 红石；材料 1000 金币
- 装备条件：Child **6★、Lv.60、觉醒 100%**
- 树：起始栏位决定识别色 + 三项能力；主轴改技能，分支加第二/三词条
- 满树 **Lv.1–12**；教学帖：1 主核 + **11 狗粮核心** + **5 个同属 5★**（主路径 5、副路径 6）
- 换核：已开栏位保留，旧核销毁不退
- 材料来源话术：诸神强袭、Devil Pass、兰菲商店、莫娜紧急支援（会改）

## 2. 完整游戏需要哪些名字和描述

下面是 **文案槽清单**。发行包用原创词；纪念版/SQL/wiki 只证明槽位存在。

### 2.1 道具目录（每件一条）

| 字段 | 为什么需要 | 原作证据 |
|---|---|---|
| `name` | 卡片标题、背包、掉落、确认框 | 截图有中文名；SQL `item.name` 韩文 2952 |
| `flavor` | 卡片 1–2 行 T5 灰字 | 装备模态有 flavor |
| `icon` 说明（不是字） | 金属静物，不是人物 | `112_saaya_weapon.png`、画风「装备图标」 |
| `slot` | 只能进对的井 | 四圆 + SQL category 1/2/3/8 |
| `rarity_star` | 1–5★（展示可到 6） | `item.grade`；武器 5★ 为主 |
| `rarity_letter` | SSS…A 叠在图标上 | 截图 SSA/SSS/A |
| `base_stats` 标签 | HP 攻擊 防禦 敏捷 暴擊 | 卡片五维格；wiki 表头相同 |
| `enhance_cap` 文案 | 「+15」 | 强化表 15 列 |
| `uncap` 文案 | 装备突破档 | `over_limit` 1–5 |
| `sell` / `buy` | 卖出确认、商店价 | `sell_price_*`；核心/材料卖价在点火 intro |
| `stack?` | 材料可叠、装备实例不叠 | `item.is_stack`；`user_item.count` |

战斗三槽 + 魂卡位是最小可玩。人偶、造型券、温泉摆设可以后做，但 **材料名** 只要有吞噬/强化就要写。

### 2.2 槽位与空态（UI 短句）

| 槽 | 建议键 | 纪念版用字 |
|---|---|---|
| 武器 | `slot.weapon` | 武器 |
| 防具 | `slot.armor` | 防具 |
| 饰品 | `slot.accessory` | 裝飾品 |
| 魂卡 / 残章 | `slot.carta` | 魂之歌牌 / 魂之歌碑；重构用「残章」 |
| 空槽 NOTICE | `equip.empty` | 未裝備任何物品。 |
| 已装备态 | `equip.equipped` | 黄药丸「已装备 / 确认」语法（视觉图鉴） |
| 更换确认 | `equip.replace.confirm` | 未拍到原文；需要「换下当前装备？」 |
| 卸下 | `equip.unequip` | 未拍到 |
| 锁定 / 保护 | `item.protect` | SQL `protect`（防当狗粮） |
| 无法装备（职业/等级） | `equip.fail.*` | 点火有「6★/60/觉醒」条件句 |

详情四列标题：`stat.col.child` / `affection` / `gear` / `inlay` = Child · 好感度 · 裝備 · 裝備鑲嵌。

### 2.3 稀有度与品级字母

两套并存，不要合成一套彩虹。

| 层 | 用在 | 文案 |
|---|---|---|
| 星 1–5 | 目录、掉落框 | `1★`…`5★`；1★ 原作功能是 **升级材料**（史莱姆/方块/金币/动物） |
| 字母 SSS–A | 装备图标角标、词缀条 | SSS SSA SS SA S SB SC SD AA A |
| 魂卡 普/闪 | 第四槽 | 普卡 / 闪卡（已有 156 特效文） |
| 人偶档 | 人偶，不进三井 | 传奇 / 史诗 / 稀有 / 罕见 / 常见（看板 220） |

### 2.4 词缀名（装备镶嵌 + 点火红字）

装备三条 `plus_option_*` = 纪念版「裝備鑲嵌」。SQL `item_option.skill_type` 1/2/3/4 → TAP/SLIDE/DRIVE/LEADER 门；0 = 通用 2606 条。`value_type` 1/2 ≈ 固定 / 百分比。

截图里已经出现、完整游戏必须覆盖的 **效果句型**（写原创句，保留句型）：

| 句型 | 截图例 |
|---|---|
| 全部能力 +N | S 全部能力 480 / SS 600 |
| 攻击时 属性% → 伤害 | +10% ATK→傷害 / +12% DEF→傷害 |
| 攻击吸血 | 攻擊時回復 9.6% 傷害為 HP |
| 击杀回血 | 擊敗敵人回復 19% 最大 HP |
| Slide 吸血 | Slide 回復 7.6% 傷害為 HP |
| 受击减伤 | 受擊額外減少 3.7% HP 傷害 |
| 受击回血 | 受擊回復 27% 傷害為 HP |
| 减益回避 | +18% / +20% 減益迴避 |
| Drive 表 | 受擊 10% 機率 Drive 表 +8%；Drive 攻擊時 Drive 表 +200 |
| 模式门 | PvP 增幅攻擊力 +220 |
| 未解锁 | 強化+5/+10/+15後可以新增追加能力 |

加工系统摘要还点名：「攻击力增加」、SlideSkill 伤害增加、攻击吸血。

点火 **官方四主核名**（intro）：增幅攻击力、增幅防御力、增幅敏捷度、增幅暴击。每核三条（1 固定主 + 2 随机）。UI 还要：邪恶之树、起始栏位、主轴、分支、点火仓库、核心材料、红石。

技能点火 U：改段数/目标（夏娃 1→2、2→3×2 等）。那是 **角色技能文**，不是道具名，但确认框要写「此核心将改变技能」。

### 2.5 材料 / 狗粮 / 货币

没有独立「材料图鉴」进纪念版表。SQL 把材料、券、人偶、装备塞进同一 `item`。完整游戏仍要分组名。

| 类 | 用途 | 文案要点 |
|---|---|---|
| 经验狗粮 | 升级吞噬 | 1★/2★ 素材名；确认「将消失、无法还原」 |
| 进化素材 | 满级 + 同星 → 星+1、等级回 1 | 视觉图鉴成长层 |
| 突破本体 | 重复卡 +0…+6 | 「突破 +N」 |
| 点火核心材料 ×99 | 造石 | 四种材料名 + 商店「50 水晶/个」 |
| 狗粮核心 | 填树 11 个 | 和主核区分；新手文案：不要拿极品去填副坑 |
| 狗粮 5★ | 主路径 5 个同属 | 「原生 5★；进化/强化型不可」 |
| 缟玛瑙 / Onyx | 点火阶段 + 好感/觉醒 | SQL `onyx`；视觉图鉴好感用 Onyx |
| 金币 / 水晶 / 红石 | 打造、买材料、卖核 | gold / gem / blood_gem |
| 温泉礼物 | 好感 | 灯笼、浴巾、皮肤箱（玩家帖）；SQL spa 堆叠 101011/101021 |
| 券 | 抽卡/装备/人偶 | **BAN 无限券**；若本地发放要原创短名 |
| 模式币 | 商店 | dungeon / arena / raid / spa / world_boss / skin_coin（SQL `do_login`） |

`do_login` 钱包列（语法，不发行原名）：`gold` `gem` `blood_gem` `friend_point` `onyx` `dungeon_coin` `arena_coin` `arena_trophy` `skin_coin` `raid_coin` `spa_coin` `world_boss_serial_coin`。

| Raid / 世界王 / 诸神强袭 | 点火材料 intro |

### 2.7 强化 / 加工 / 点火 / 温泉 / 还魂 确认框

完整游戏至少要这些 **会吃掉东西** 的确认（纪念版多半没拍到正文，SQL/wiki 证明动作存在）：

| 动作 | 必须写清 | 原作警告 |
|---|---|---|
| 装备强化 +1…+15 | 消耗、失败与否、新词条解锁点 +5/+10/+15 | 锁条原文见上 |
| 装备突破 | 消耗、不可逆 | over_limit 表 |
| 镶嵌 / 加工 | 覆盖旧词缀？ | 37396 |
| 卖出装备/核心/材料 | 价、绑定、已装备不能卖 | 核心 7 红石；材料 1000 金 |
| 锁定/解锁 | 防吞噬 | `protect` |
| 吞噬升级 | 列表 + 「消失无法还原」 | 点火 intro 同句 |
| 进化 | 满级条件、星+1、等级回 1 | 视觉图鉴 |
| 突破角色 | 重复本体 | 视觉图鉴 |
| 打造点火核 | 99 材料 + 一只原生 5★ + 15 万金 | 用掉不返还 |
| 装上起始核 | 不退还 | intro |
| 填主/副路径 | 主路径：核+同属 5★；副路径：只要核 | 教学帖 |
