# 11 · 游戏模式文案盘点

盘的是**屏上会看见的字**：标题、规则说明、奖励签、排名、剩余时间、难度名。不是配队攻略。

对照：`总看板.html#modes`、`星云一趟.html#modes`、`战斗动效.html#modes`、`docs/reference/gamekee/parsed/`（公式一条，无模式词条表）、`docs/reference/gamekee/tables/README.md`（天子/魂卡/人偶，无模式表）。

覆盖码：

| 码 | 意思 |
|---|---|
| **屏** | 截图 / 录像里能读到原文 |
| **wiki** | GameKee 词条（玩家文或官方说明图） |
| **SQL** | 韩服 dump 证明结构，**没有关卡标题** |
| **提案** | `星云一趟.html` 自造示意，不是原作 UI |
| **无** | 这仓库里没有 |

`parsed/` 没有模式原文表。魂卡门 `mode_gate` 才是表里和模式挂钩的标签（156 张里 153 有门）：`pvp` 42 · `通用` 37 · `rb` 29 · `wb` 22 · `5人巨型boss` 10 · `pve` 5 · `20人巨型boss` 4 · `太空漫步` 3 · `地铁` 1。

## 1. 主线（世界地图战役 / 主线剧情）

**别名：** Episode、World Map、剧情关、`game_area_dungeon` `area_type=1`。

**屏标题**

- 内容地图：`世界地图战役`、`主线剧情`
- 进战：`第7關 第二次死亡`、`第1關 教學1`（繁中 wiki 77671）
- 编队条：`4 TEAM` / `6 TEAM`、`5TH TEAM`、`LEADER`、`戰鬥力`
- 按钮：`編輯隊伍`、`自動戰鬥`、`戰鬥開始`、体力 `-25` / `-2`
- 战场顶：`>> ×3 SPEED`、`FULL AUTO`、`PHASE 1/3`、`04:55`、`PAUSE`、`BATTLE`
- 底栏：短名、`60 MAX`、`FEVER 0%`、全队 HP%
- 日服编号 HUD（GameNext，视觉图鉴转述）：①敌信息 ②倍速 ③剩余时间 ④自动 ⑤技能环 ⑥Slide 冷却 ⑦Drive ⑧Drive/Fever/总 HP

**规则说明（屏）**

- `與好友同行可獲得額外增益。員無法戰鬥的話，他們將會加入戰鬥。`（好友助战条；截图左侧被裁，首字残）
- 自动结束弹窗 `NOTICE`：`選取結束自動戰鬥的條件。` / `Child/物品欄全滿。` / `Child達到最高等級` / `戰鬥敗北` / `發現副本` / `*體力或入場數耗盡。` / `*即使戰鬥增幅因為無法購買而停用，戰鬥也會繼續。` / `確認`
- 攻略贴纸（不是游戏字）：手动 / 半自动 / 全自动；`剧情1带4, 狗粮死了不影响经验和奖励收益`

**奖励签（屏）**

- `出現Child`（三头预览）
- `可能獲得獎勵`（金币、素材、装备格）
- 好友条右：`+5` 勋章
- 技能预设三钮：`攻擊力+10%` `防禦力+10%` `HP+10%` 各 `1,000`（标注「只在非竞技场生效」）
- SQL：`star_count=3` → 三星清关语法；`area_gift_type` 章节礼

**排名：** 无天梯。三星是关卡章，不是 Rank。

**剩余时间：** 战场顶 `04:55` 一类倒计时。大厅无赛季钟。

**难度名**

- SQL：`area_type` 1 / 2 各 152 套（普通 / 困难假设，镜像 id）
- 30 `area_idx`；关卡链 `need_dungeon_idx`；每关最后一战 `is_boss_stage`；`phase_count` 几乎都是 3
- **不要用 dump 里的关卡标题**（`03-content-loops.md` 硬禁）

**缺口：** 世界地图点选、章节名完整表、结算「過關」屏、三星条件原文。纪念版无战斗。

## 2. 困难（主线第二套）

**别名：** Hard、`area_type=2`、星图语境里的「困难」不要和星云困难混。

**屏标题 / 规则 / 奖励 / 时间：** **无**独立战场图。动效页写死：铬 = 主线（PHASE、5 圆、圆台），只换入口难度签和敌面板。

**难度名（SQL）**

- 困难是 **30 条分章链**，不是第二条 152 长脊
- 每章困难开门 = 该章普通最后一关（例：`1010` 需要 `1007`）
- 体力：后段普通 `end_stamina=24`，困难 `29`

**wiki：** 韩服有「星图困难1-2 / 困难3」——那是**星云**，不是主线困难。

**缺口：** 入口上的「困难」签、颜色、是否写 HARD / 困難。复刻不要另做 HUD。

## 3. 星云（空间唤醒 / 太空漫步）

**别名：** Spacewalk、星图、人偶生效场。SQL `game_spacewalk_area_dungeon` 256 × 8 关 = 2048。

**屏标题**

- 内容地图：`空间唤醒`（飞碟磁贴）
- wiki 90679：`太空漫步`；结构用语 `行星`、`区域 ZONE`、`星云之主`
- **无**原作星云战场录像；顶条按主线（关卡名/波次，不是 20 头）

**规则说明**

- wiki：8 行星 ×（8 小关 + 1 Boss）→ 文内写「加上 boss 一共 520 关」；韩服 SQL 已扩到 32 区 / 2048 小关
- 人偶「可以在星主中生效」（wiki 169618）
- 波次：星云 `phase` **恒为 1**（主线几乎 3）
- **提案**（`星云一趟.html`，不是原作）：`NEBULA` `一趟 · 8 点`、`STAR CORE` `三选一`、`REST` `休整`、`MERCHANT` `星屑 × 40`、`CLEAR` `出星云`、`PARTY 07` `编队`、`进入星云`、`本趟词条 · 出星云作废`
- 提案节点名：哨站 / 星核碎片 / 星屑带 / 休整 / 近核 / 行商 / 星核

**奖励签**

- 用户表字段：`is_reward_get`（SQL，无文案）
- 提案：`星屑绷带`、`本趟同行`（人偶出星云回去）
- 魂卡门：`太空漫步` 3 张

**排名 / 剩余时间：** 原作无赛季榜。无大厅倒计时图。

**难度名（wiki）**

- 普通速刷、星图困难 1–2、困难 3、星云 4
- 星主 Boss 俗称：星主岛夫人 / 狐狸 / 亚里亚；作业里还有「困难星云火 boss」
- changelog：「星云普通关卡修复，可以尽情打一千多关」

**看板一句：** 「5 人圆台，换背景。SQL 2048 关 / 无战场录像。」

**缺口：** 原作选关列表、ZONE 编号怎么写、Boss 关标题、掉落签、是否有「困难」页签。提案字不要当原文用。

## 5. 世界王（World Boss Trial）

**别名：** WB、世界巨型首领、`world_boss_serial_*` 季 1–38。魂卡门 `wb` 22 + `20人巨型boss` 4。

**屏标题**

- `WORLD BOSS TRIAL`、韩译 `월드보스·트라이얼`
- `28TH BOSS` / `4TH BOSS` / `1ST BOSS` …
- `TRIAL READY` / `전투 준비`
- `PRACTICE MODE`
- `BOOST CHILD`
- `보스 정보` `전장 버프` / `Battle Buffs`
- 底栏英：`Trial List` · `Magic Mirror Shop` · `Trial Mission` · `World Boss Rank` · `Help`
- 底栏繁：`試煉清單` · `魔鏡商店` · `試煉任務` · `世界王排名` · `說明`
- 底栏韩：`트라이얼리스트` · `마경상점` · `트라이얼 미션` · `월드보스 랭크` · `도움말`
- 战场 Boss 名例：`210 Passionate Ruler Aurora King`、`옥염의 군신 솔`、`Vicious Khepri`
- 结束叠字：`100TH HIT` + 白字伤害（例 `3,308,051`）——**不是**擊滅金环

**规则说明（官方说明页，`wb_intro_01.png`，繁中）**

标题：`WORLD BOSS:TRIAL INFORMATION`

> 世界王出現了！  
> 所謂的世界王，是指惡魔和 Child 經過失控的魔鏡現象所誕生出的凶惡敵人。  
> 與各地的魔王候補生一同戰鬥，以擊敗世界王並獲得獎勵吧。  
> 挑戰世界王需有世界王券。

> 含有20名Child的大型戰鬥！  
> - 全自動(無法使用手動遊玩)  
> - 自動啟用 Drive Skills，和戰鬥準備螢幕的 Drive 順序設定相符。  
> - Fever Time 時，每名可以進行攻擊的 Child 都會依序攻擊。  
> - 世界王會優先攻擊前排的10名（減益和自動攻擊除外）。  
> 戰鬥後若點擊再次試煉，將能使用 1 張世界王券並再次造成最近一次戰鬥中已造成的傷害。每名世界王只能使用一次。

> 收集魔鏡碎片並獲得獎勵！  
> 魔鏡碎片可由世界王戰鬥、勝利獎勵和每日排名獎勵中取得，在魔鏡商店中交換。  
> 增幅型 Child 參與時，戰鬥和每日排名有額外魔鏡碎片，**無法從勝利獎勵中獲得**。

> 當世界王被擊敗時，每個人都會獲得獎勵！排名愈高，獎勵愈豐厚！  
> 勝利獎勵每個魔王候補生都可取得；打满一定次数后有更好的胜利奖励。  
> 排名分每日排名（每日累计总伤害）和每季排名（每季累计总伤害）。  
> 每日排名奖励：前一次每日标籤，只能领前一次计算后的；务必在下次计算开始前领取。  
> 每季排名奖励：出现期间和成绩计算结束后，从每季标籤领取，发到信箱。

## 6. PVP（恶魔挑战 / Devil Rumble · 无尽对决）

**别名：** 恶斗擂台、日常 5V5、Rumble。魂卡门 `pvp` 42。无尽对决 / Endless Duel / Engarde 是后期规则 PVP，同入口行。

**屏标题**

- 内容地图：`恶魔挑战` + `DEVIL RUMBLE` `PVP`；旁格 `Dual On Guard` `On Guard开放!`、`ENDLESS DUEL ENGARDE`
- `队伍编辑`、`拥有入场券个数` `4/10`、钟 `14 59`
- `连续挑战`、`更新列表`
- `SKILL RESERVE`：`可以随意设置技能使用顺序.` `天子在自动战斗时根据设定的技能顺序来使用.`
  - `DRIVE`：`Drive技能可根据每个小队的顺序来指定.`（截图拼写 `Drieve`）
  - `NON DRIVE`：`重击,滑动技能可根据天子的顺序来指定.` 槽位 `S` / `E` / `N`
  - `1 PARTY` … `3 PARTY`、`设置`

  - `入场券使用 100个后结束`
  - `连续挑战中 1次胜利时结束` / `1次战败时结束`
  - `挑战硬币 / 金币 / 积分达到 MAX 后结束`
- 乱斗选赛（`kr_rumble_02`）：`选择要参加的比赛.` `可同时参加多个比赛.`
  - `无限大乱斗 12`：`排除光属性和 特定天子的 15名天子战斗`；`赛季时间：2022年 10月 13日维护前截止`
  - `FRONTIER DUEL` 本源 3星以下 天子15人战斗
  - `EXPERT DUEL` 4星以下
  - `UNLIMITED DUEL` 无限制 15人自由战斗
  - 右签 `参战中`

**规则说明（wiki）**

## 7. 地铁（地狱地铁）

**别名：** Underground 的后期延伸不是同一入口——内容地图 `地下组织` 是早期 Underground；地铁从**世界地图**进（wiki 167124）。魂卡门 `地铁` **1** 张。

**屏标题：** **无**大厅/战场截图。wiki 标题：`地铁介绍`、`地狱地铁入门`、`地铁-地狱-指路贴`。

**规则说明（wiki 摘要）**

- 从世界地图进入
- **四种难度**，通关一层解放下一档
- 有剧情（167124 摘要被截在「我没」）
- 地狱：通关「极地铁」后开放；再分 **弱、中、强**
- 掉落「天然石」，做地铁新套装必需（576728）

**奖励签（wiki）：** 天然石、新套装、彩色附魔（另页 `彩色附魔指南`）。无屏上「可能獲得獎勵」裁图。

**排名 / 剩余时间：** 无。日常一次（是否重置指向挖矿攻略）。

**难度名：** 四档（wiki 未在摘要里写出四档官方名）+ 地狱 `弱 / 中 / 强`。玩家：「极地铁」。

**早期 Underground（研究报，全球资料，非本仓库截图）：** 15 场、每三胜奖励、HP/Drive 继承、当日阵亡禁用。与地铁是否同一套铬 **未用录像证明**。

**缺口：** 四档官方名、层数怎么写、进战按钮、天然石图标上的字。覆盖最差的常驻 PVE 之一。

## 8. 5人Boss

看板魂卡门：「模式门：PVP 42 · 通用 37 · Ragna 29 · 世界王 22 · **5 人 Boss 10**。」

**屏标题 / 规则 / 排名 / 时间 / 难度：** **无**独立大厅。卡特效句式：

- `5人巨型boss，装备时…`
- `在5人巨型boss中装备时…`
- `在5人巨型boss中，攻击时回复HP…`

- `chapter_boss_mob` **10** 行：4 个身份 × HP 梯；`hp_phase=20`；`user_chapter_boss_party` 20 uid（四桌 5 人）

**缺口：** 入口在活动本还是世界地图、标题英/韩/中、是否和「诸神炸裂」单人副本同一皮。目前只能当魂卡条件标签。

## 复刻时别混的几句

1. 韩服把 Ragna 叫 Raid；结算仍写 `RAGNA:BREAK COMPLETE`。
2. 主线困难 ≠ 星云困难 ≠ 地铁地狱。
3. `地下组织` ≠ `地铁`；`空间唤醒` = 星云。
4. 世界王结束是 `100TH HIT` 刮血，不是擊滅。
5. `星云一趟` 的 `三选一 / 星屑 / 出星云作废` 是提案。
6. `5人巨型boss` 是魂卡条件，缺模式皮。
7. dump 关卡名不进发行包；只复用「章 → 线性关 → 可选困难」语法。
