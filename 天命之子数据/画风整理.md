## 0. 一句话

《Destiny Child》的识别资产不是战斗 UI，而是：

**韩国一线游戏插画的厚涂全身立绘 + 暗奢时装碰撞 + 让插画“呼吸”的 Live2D。**

它不是日式赛璐璐番剧风，也不是欧美写实，更不是“胸像塞进圆框”的通用抽卡默认。舞台永远是：**近黑虚空里站着一个被打亮的完整人体。**

## 2. 血统（为什么长这样）

- 开发：**SHIFT UP**。导演兼角色设计：**金亨泰（김형태 / Kim Hyung-tae）**。
- 同一条河的下游是后来的 NIKKE、Stellar Blade：都是「身体即设计、时装即世界观」。
- 原画团队不只有金亨泰。同期公开提到的还有血羅（角色/Boss）、KKUEM 蔡知玧（高饱和、优雅）、tokkihouse 等韩国商业插画师。所以图鉴里能同时看到：暗奢哥特、糖果色偶像、学院日常、兽人、怪物。
- Live2D Creative Studio 的制作说明写得很死：

> 游戏内插画基本是**厚涂全身**；从一张原画细切素材。头发根部与发梢至少两套参数；关节分上下肢；还要能前后纵深，不只左右摆。站姿角色强调呼吸，浮空角色做成失重飘。

结论：画风的第一原则是 **「先当商业插画海报，再当可动纸娃娃」**，不是「先当骨骼动画再贴皮」。

年龄分级：Google Play Memorial 标 Mature 17+（暴力、血腥、部分裸露）。性感是原作产品识别的一部分，但**复刻发行时要主动降风险**：学比例与时装密度，不要学具体暴露剪影。

## 3. 核心技法：厚涂全身，线服务于形

| 维度 | 原作怎么画 | 复刻时要留下的感觉 |
|---|---|---|
| 媒介 | 商业厚涂插画，不是赛璐璐平涂 | 皮肤有体积和次表面，衣服有材质照片感 |
| 线稿 | 细、软，常被颜色吃掉；轮廓靠明暗而不是黑边 | 干净外轮廓 + 内部少用死黑线 |
| 单位 | **全身一张海报** | 头到脚都要设计，腿和鞋不是省略项 |
| 背景 | 立绘本身常是透明/虚空；游戏里再叠棋盘与火星 | 角色必须在纯黑上仍然好看 |
| 细节密度 | 服装扣件、纹样、饰品、发丝分层极高 | 主剪影清晰，近看有「买得起的 denseness」 |
| 动态 | 插画活过来：呼吸、发、布、胸腔、饰品、视差 | 不需要跑跳循环 |

**不要画成：** 平涂二次元、厚涂到照片、美式漫画网点、Q 版当主展示（Q 版只给人偶/夏娃）。

## 4. 人体与比例

5★ 主力（图鉴 282 人这一档）是时装模特骨架，不是萌系 5.5 头身。

| 档 | 头身 | 体态 | 用途 |
|---|---|---|---|
| 5★ 时装女 | 约 7.5–8.5 头 | 长腿、细腰、明显胸臀曲线、颈长 | 主展示、Home、详情 |
| 5★ 日常/学院 | 同上，曲线收敛 | 裙、衬衫、书包，仍是成人比例 | 同一套渲染，换「概念」 |
| 5★ 怪物/龙/史莱姆 | 非人 | 剪影当生物设计，仍是厚涂 | 队伍里允许「非美人」 |
| 男性 / 中性 | 偏薄的时装男或神话中性 | 脸仍是插画美型，不是硬汉写实 | 图鉴有，但不是视觉中心 |
| 人偶 / 夏娃 | 2.5–3.5 头 Q 版 | 头大手短，服装颜色继承本尊 | 另一套登记，见 §11 |
| 1★ / 2★ 素材 | 物化、吉祥物 | 史莱姆、骰子、金币、动物 | 养成饲料，不要画成低配时装 |

站姿规则（详情页反复出现）：

1. 脚不钉死地面，常微浮；脚下有接触阴影或一圈属性能量。
2. 对侧站（contrapposto）：一侧髋抬起，重心在一条腿。
3. 手一定做事：持武器、提包、扶眼镜、比心、插腰、举杖。空摆的手几乎没有。
4. 道具是概念的一半：蒸笼、公路车、南瓜、双狙、头盔、步枪箱。

**复刻禁区：** 把主界面做成胸像圆形卡。原作 Home / 详情 / 图库全部是全身。圆角方头像只给列表和图鉴。

## 5. 脸、五官、头发

头像库（`avatars/`）是 1:1 圆角方图，最适合看脸。

**脸**

- 结构是「成人向商业插画脸」：眼距近、下颌尖、鼻梁用高光而不是线。
- 眼睛大，但不到萌系圆眼。虹膜多层：固有色 + 一圈高饱和边缘 + 两颗捕光。
- 常见妆：眼线、眼影、唇彩。即使是「学院」角色也有妆，不是素颜番剧。
- 嘴：微张、露齿笑、嘟嘴、冷静闭唇。表情是角色设计的一部分，不是统一微笑模板。
- 肤色：暖桃、冷白、浅褐都有；一定有脸颊血色和耳朵/关节的红。

**头发 = 第一图形**

- 发量经常超过躯干投影。双马尾、长直、大卷、异色挑染，都当「第二剪影」来画。
- 颜色敢用：冰薄荷、玫红、金、银白、双色。衣服可以很黑，头发负责彩度。
- Live2D 把它拆成前/中/后层，根部硬、梢部软。静帧里也要能看出这种分层（刘海、侧束、主发、尾）。
- 头饰密度高： Horny、花、贝雷、兔耳、星形贴片、眼镜、眼罩。头饰要能跟着头动。

**头像裁切**

- 构图：下巴到头顶留边，肩膀切一刀。不是大头贴，也不是全身缩小。
- 5★ 角标：左上属性菱形 + 金星闪。框色 = 属性（火红 / 水蓝 / 木绿 / 光金 / 暗紫）。

## 6. 服装：概念碰撞（这是 DC 最特殊的一层）

原作角色名字来自神话、恶魔学、历史；**身上穿的经常是当代时装或亚文化套装**。这不是「盔甲女战士」游戏，而是：

> 用一件能在时尚杂志成立的衣服，去翻译一个超自然概念。

从本机截图直接读到的碰撞例子（只作语法，禁止照搬造型）：

| 概念 | 穿成了什么 | 语法 |
|---|---|---|
| 暗魔女王 | 黑束身、长靴、火焰丝带 | 哥特 + 夜店剪裁 + 元素特效 |
| 都市日常 | 红T、裤袜、平底鞋、蒸笼 | 完全当代，靠头身和渲染仍是 DC |
| 学院 | 白衬衫、粉皮裙、手提包 | OL/大学生，皮革反光是关键 |
| 竞速 | 黄黑连体车衣 + 公路车 | 运动品牌图形印在身上 |
| 暗影特工 | 白裙 + 束缚带 + 步枪箱 | 洛丽塔结构 × 战术装备 |
| 女仆 | 黑白蕾丝，双人构图 + 猫 | 服饰类型本身就是主题 |
| 万圣 | 坐在巨大南瓜上，糖果与蝙蝠 | 节日活动皮肤：道具大于衣服 |
| 兔耳车手 | 赛道服 + 大兔耳 + 头盔 | 兽耳是装饰，不是兽人解剖 |
| 狙击 | 女仆连体 + 双枪 | 「职业道具」放大成主图形 |

材料混搭是标配，一张身上会同时出现：

皮革、金属扣、薄纱、蕾丝、珠宝、乳胶/漆皮高光、针织、运动网眼、军靴、细高跟鞋。

**复刻时真正要学的：**  
每个原创角色先写一句「概念 × 时装类型」，再画。不要先画一套通用盔甲再换头发。

造型系统（衣柜 / 图鉴「造型」315 套）证明：同一张脸可以换完全不同的时装宇宙，脸和发色锁身份，衣服锁活动。

## 7. 材质、光、舞台

### 7.1 角色光

- **主光：** 画面左上暖光（橙 `#FF8C00` 一带），扫脸、锁骨、大腿前侧。
- **轮廓光：** 头发和肩膀有一圈亮边，把人从黑底抠出来。
- **体光：** 躯干后方一团暖径向光（`fx.underGlow`），没有它，黑棋盘会像漏装天空盒。
- **皮肤：** 次表面散射，不是一层平涂肉色。关节、胸口、脸颊更饱和。
- **材质高光：** 漆皮/皮革是条状高光；金属是硬点；纱是透叠。

### 7.2 舞台（Presenter：Home / 详情 / 图库）

- 清场色：纯黑 `#000000`。
- 地面：透视棋盘，深块 `#101012` × 浅块 `#2A2934`（偏蓝灰，**不是棕木地板**）。格子大，向灭点缩小，底部重暗角。
- 空气：稀疏的橙金火星，有的在人前面，有的在人后面。
- 角色占屏高约 70–80%。脸在上三分之一，字打在大腿位置。

图库模式（`027`）把 UI 剥光：只剩人和棋盘。**关掉 UI 仍然要像完成品。**

### 7.3 不要混的两套地板

| 舞台 | 用在 | 地面 |
|---|---|---|
| Presenter | 首页、详情、图库 | 透视棋盘 + 暗角 + 火星 |
| Mosaic | 编队、图鉴网格 | 45° 菱形砖 + 心/星/100 水印 |

温泉是第三套：写实园林风景，角色泡在水里。图书馆是木书架。夏娃是金框地牢。MVP 不要用雕刻胡桃木去冒充主界面。

## 8. 色彩纪律

角色可以很花；**界面几乎不花**。彩度是配额。

| 层 | 规则 |
|---|---|
| 世界底 | 黑 / 炭 / 白 |
| 价值 | 金黄。战斗力数字必须是 `#FFC400` 这一档，不能用白 |
| 选择 | 更亮的金 `#F8BA00` 描边 |
| 确认按钮 | 柠檬→蜂蜜渐变胶囊，深描边 |
| 属性 | 火 `#D02018` / 水 `#1C8DE1` / 木 `#2F900A` / 光 `#D0B33D` / 暗 `#814B98`。光属性金必须比「选中金」暗，否则光角色会看起来像被选中 |
| 红星 | 已拥有进化体：红五角星。图鉴筛选：金星。不要混 |
| 角色本体 | 头发和高饱和局部负责个性；衣服经常是黑、白、一组强调色 |

完整色板、字号、组件配方见 `VISUAL_LANGUAGE.md`。那份是 UI；本份是插画。两边共用「黑底 + 金强调 + 属性框」。

## 9. 姿态、构图、文字叠图

竖屏 9:19（证据分辨率 1200×2670）。

```
[            近黑虚空 + 火星            ]
[     全身角色（中轴，约 80% 屏高）     ]
[  右缘工具条（小、灰、不抢脸）          ]
[                                       ]
[  左下：名字 / 台词 / 星 / 属性 / 职业 ]
[  数值（战斗力一颗大黄字）              ]
[  底：四装备槽 + 技能胶囊   或  六页签 ]
```

- 脸和上半身保持干净。字从约 60–65% 屏高开始压在腿上。
- 名字：白 + **很厚的黑描边**（没描边会死在头发和棋盘上）。
- 台词一行，灰白，同样描边。
- 编队列表把全身裁成**高竖条**：头顶用网点（halftone）溶进黑底，不要硬切矩形。

## 10. Live2D 运动语法

官方确认用 Cubism 2。要学的不是「动作条数」，是**分层够细**：

必须能动的层：瞳孔 / 眼皮 / 嘴 / 脸微转 / 头发前中后 / 胸腔呼吸 / 肩 / 袖 / 裙摆或披风 / 饰品摆 / 前后景视差。

| 姿态类型 | 待机 |
|---|---|
| 站立 | 呼吸 + 发梢慢摆 |
| 走路（Home 可出现） | 轻盈步伐，不是跑 |
| 浮空 | 失重上下漂，脚下能量圈 |
| 坐/骑道具 | 道具是刚体，人在上面呼吸 |

MVP 可以用静帧 + 轻微 bob，但资源规范仍按「将来能切 Live2D」来画：肢体不要画死在极端透视里，发块要能分开。

## 11. 六套视觉登记（不要画成一种东西）

同一产品里至少有六种「画」。主界面用 1，列表用 2，不要串种。

### A. Presenter 全身立绘（产品脸面）

厚涂全身、黑棋盘、火星、字压腿。Home / 详情 / 图库。

### B. 列表头像（信息密度）

- 编队：高竖条，网点溶解，左下等级，黄 `+N`，竖排红星，属性/职业圆标。
- 图鉴：圆角方砖，**属性色框**一眼可读，名字在砖下，角上 U/P/S 徽章。6 列，缝极窄。
- 空砖：主题水印（心、颅、火），不是白板。

### C. 魂之歌牌（场景插画）

这是另一套原画预算：角色被放进**有环境的画面**（海边、房间、节日），不是虚空。

- 竖构图，银/铁丽纹框，顶上 `soul carta` 字标。
- 卡面常有虹彩膜、光斑、网格高光（像闪卡）。
- 底部叠短台词 + 两项数值 + 属性。
- 气质更「商业插画封面 / 塔罗」，比 Presenter 更叙事。

### D. 人偶（Q 版继承色）

大头短身，服装配色跟本尊走，金玫瑰/巴洛克框，英文 `Puppet` 锁字。这是可爱登记，渲染仍偏厚涂小雕像，不是贴纸 Q 版。

### E. 场景关（温泉 / 图书馆 / 夏娃）

| 关 | 气质 |
|---|---|
| 魔界温泉 | 厚涂风景：夕光、鸟居灯笼、松石水、蒸汽。角色是景中人 |
| 黑卡蒂图书馆 | 木、金匾、故事卡肖像、魔女吉祥物半身 |
| 夏娃冒险 | 金丝藤蔓镜框 + 地牢瓷砖 + 豆人，SHIFT UP 署名在框上 |

常量仍是：**暗底 + 金控件**。变的是布景，不是按钮语言。

### F. 装备图标

金属静物小图：斧枪、锤、披风。品级字母（SSA / S / SS / AA）叠在图标上。这是道具设计，不是人物。

## 12. 稀有度 = 设计预算，不是换色

| 星 | 人数（图鉴） | 画 |
|---|---:|---|
| 5★+ | 282 | 最高时装密度、独特剪影、专属特效、常有道具场景 |
| 4★ | 77 | 仍是完整插画，装饰略减 |
| 3★ | 99 | 更简单的套装，脸仍是同一套五官语法 |
| 2★ | 53 | 转向吉祥物 / 素材 |
| 1★ | 50 | 史莱姆、方块、金币、动物，功能是升级材料 |

复刻 MVP 如果只有十几名原创角色，应全部按 **5★ Presenter 预算** 画，另做 1 套 Q 版人偶和 1 套魂卡场景即可。不要用 1★ 史莱姆的简化法去画主力。

## 13. 和 NIKKE / 泛二次元抽卡的差别（防画飘）

| | 天命之子 | 别画成 |
|---|---|---|

## 14. 给原画 / 生成器的锚点（Clean-room）

下面这些句子描述**语法**，用来画原创角色。不要在提示词里写原作角色名。

### 14.1 Presenter 全身（主用）

> High-end Korean mobile-game character illustration, thick painterly full-body, fashion-fantasy, adult fashion-model proportions, huge graphic hair with cinematic rim light, peach skin with warm subsurface scattering, thin almost-lost linework, costume is a high-fashion mashup of modern clothing and occult ornament, standing on a dark perspective checkerboard in a near-black void, sparse orange ember motes in the air, warm key light from upper left, character is the only light source, Live2D-ready clear silhouette.

中文对照：韩国高端手游角色插画；厚涂全身；时装奇幻；成人模特比例；头发当主图形并带轮廓光；皮肤暖桃有透光；线细到几乎被颜色吃掉；服装是当代时装与密教饰件的混搭；近黑透视棋盘；空气里稀疏橙金火星；主光左上暖；角色自己发光；剪影清楚，方便以后切 Live2D。

每张角色另加一句 **「概念 × 时装类型」**，例如：`夜巡神偷 × 束带白裙与长步枪箱`，不要只写「一个漂亮女孩」。

### 14.2 图鉴方头像

> Square rounded portrait crop, face and shoulders only, same thick-paint Korean illustration face, detailed iris and makeup, element-colored rim, dark background, no UI text.

### 14.3 魂之歌牌

> Vertical cinematic illustration of the same character inside a real environment (not a void), ornate silver filigree card frame, subtle holographic rainbow overlay, tarot-poster composition.

### 14.4 人偶

> Super-deformed chibi of the same adult character, oversized head, short body, outfit colors inherited, gold baroque frame, still slightly painterly rather than sticker-flat.

### 14.5 必须写进每一张提示的冻结项

- 全身（Presenter）或规定的裁切（头像/卡面）
- 厚涂，不是平涂
- 黑底或棋盘，不是房间（除非魂卡/温泉）
- 成人比例（主力）；Q 版只给人偶
- 无文字、无 Logo、无原作纹章
- 手要抓住道具

## 15. 反模式（一看就是外服换皮）

- 默认 Unity 蓝按钮、Arial、浅灰面板。
- 用一张胸像当首页。
- 把棋盘换成天空或木地板。
- 一种黄用到底：导航金 = 战斗力金 = 光属性金 = 确认金。
- 编队星星涂成金色（已拥有应是红星）。
- 赛璐璐平涂、大眼睛幼态脸当 5★ 主力。
- 把人偶 Q 版放大当 Presenter。
- 抄原作具体发型、束身剪影、S CLASS、六页签图标。
- 不给头发预算：DC 的头发往往比衣服更费笔。
- 手空着、脚切掉、鞋画成一笔。

## 16. 复刻时的资产清单（画风落地）

若按 clean-room 做原创角色，每人最低要有：

1. **Presenter 全身**（透明或纯黑底，竖构图 9:16 或 9:19）
2. **方头像**（1:1，脸+肩，属性框后加）
3. **编队竖条**（可从全身裁 + 网点溶解）
4. **人偶 Q 版**（可选，P2）
5. **魂卡场景图**（可选，P2）
6. 同一张脸的 **1 套换装**（证明时装系统，不证明新角色）

先画 1 名「暗奢」+ 1 名「当代日常」+ 1 名「非人生物」，三张过关，再批量。这三张分别锁：哥特密度、日常也能是 DC、怪物也吃同一套光。

UI 色板不要重造，直接用 `VISUAL_LANGUAGE.md` 的 token。
