# 残响界·第一世界

## 世界怎么来的

很久以前神与魔把世界打裂。裂口里漏出的不是光，是“残响”——死去的神话、未被选中的名字、没能成为神的灵魂。残响凝成**契灵**。活人里极少数额上会亮**契印**，能与契灵定约，称为**契主**。

第一世界是残响界最旧的一层：废都为脐，五属城邦环绕，头顶悬着诸神残骸。本书记完这一层的兴亡，不写第二世界。

## 地理

- **废都**：文明崩后的第一座城。拾荒、黑市、金契院驻城。入口有锈门，门上刻“有契者入，无契者拾”。
- **锈轨巷**：地下旧轨，列车骨头还在，风一吹会响。
- **断桥**：连内城与浊井的唯一石桥，桥心有一道不落的缝。
- **浊潮井**：井水是记忆，喝多了会梦见别人的死。
- **棘林边缘**：会走路的荆棘，认“空地”才让路。
- **残灯回廊**：每盏灯是一个被忘掉的名字。灯灭，那人在世上彻底没过。
- **白昼裂口**：昼夜被撕开的峡谷，光属契灵的边境。
- **影缚地窟**：暗属锁库，专门关“不听话的契灵”和“不该存在的空契”。
- **炉心外环 / 炉心**：火属工业城，契灵曾被当炉芯烧。
- **城门广场 / 守核下层 / 城门守核**：废都的心脏。守核是一颗还在跳的神核，吃空契为食。
- **五属城邦**：火炉心、水潮都、木森野、光光庭、暗暗渊。各有抽契井，抽取新生儿的天赋去喂城。
- **诸神残骸**：天域碎片，上一代空契成神之处。
- **天命井**：世界规则的井口。榜上有名者有天赋；陈空的格子是空的。

## 力量规则（小说里要写清楚，不要数值表）

- **五属**：火克木，木克水，水克火；光暗互克。克制只影响契灵交手，不影响陈空（他不受属）。
- **契约**：双方同意才成。强迫契会反噬契主。金契院用锁链模拟同意，那是罪。
- **空契**：契印无纹。鉴定为废。实际是“不挤占”。可同时容纳许多契灵，但契主自己打不出残响。
- **合鸣（Drive）**：多位契灵把声音叠进空契。陈空不发招，他张开门。合鸣时世界会短暂改写一条小规则。
- **记名**：对着契灵喊她自己选的名字，比任何契术都稳。陈空的“术”就是记名字。
- **天命榜**：金契院神器。婴儿时测契，写入天赋。空格子的孩子会被建议遗弃。榜的底层连着守核，空契是它的储备粮。

## 势力

| 势力 | 表面 | 实际 |
|---|---|---|
| 金契院 | 登记契灵、保护城市 | 把契灵当武器和燃料，猎空契 |
| 白昼教廷 | 光即秩序 | 放逐保护废材的圣盾 |
| 潮后宫廷 | 水都繁荣 | 用联姻锁契灵血脉 |
| 森野旧神残部 | 守护林 | 要把空契当肥料 |
| 暗渊无名社 | 收容被删名者 | 劝陈空躺平当神龛 |
| 拾荒行 | 废都底层互助 | 陈空的出身，后期是他的人 |

## 时间

故事一年内完成。春入废都，夏过五属，秋上残骸，冬合鸣。不要写成十年升级流。

## 日常质感（必须有）

废都的早饭是糊铁锅粥。契灵会抢被。陈空的衣服永远少一件（拿去包扎）。金契院的徽章很亮，亮得像不肯脏。炉心的烟是甜的，因为烧过名字。
