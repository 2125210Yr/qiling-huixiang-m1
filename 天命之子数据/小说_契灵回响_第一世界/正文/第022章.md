# 第22章 逃奴

刀尖没有对准陈空。

冰刃把刀尖转向自己。对准自己的心口，距离一寸，稳。银白短发被井风吹得根根分明，左眼下那道旧裂像一条更直的刀。

“听清楚。”她对青潮长发的女人说，“他是契主。废的那种。逃的是编制，不是人。”

井沿很静。潮声在下面拍，拍得石栏微微发颤。拾荒者已经睡过去，睡得难看，难看总比死好看。

女人看着刀尖，并不退。她的目光从冰刃的心口移到陈空额上。

“额空。”她说。

“空。”陈空自己答。他想站，左肩不许。白昼的手按在他右肩，按住，让他坐稳。

女人伸手。这一次她先停在半空，等。等什么，陈空不懂。白昼懂。白昼说：“他允许你看，你再看。他不会的，我替他说允许。”

陈空点头：“看吧。鉴定书……也是空。”

女人的凉手指碰到他额。触感很轻，轻得像试水温。她的眉皱起来。皱得不漂亮，认真。认真看完，她把手收回来，在自己衣摆上擦了擦，像擦掉一种说不清的东西。

“真空。”她说，“不是藏纹。不是假死印。是没有。”

她的指腹在他额上停过的地方留下一小块凉。凉很快被潮气吃掉。陈空却觉得那块地方空得更明显了，明显得像被人用指头按开一扇窗。窗外什么都没有。没有才让人想往里看。

冰刃看着这一幕，喉结动了动，没骂。没骂比骂更危险。她把刀尖从自己心口又往下移了半寸，移到刚好能让自己疼、又不至于立刻见血的位置。

“看够了没有。”她说，“空也是他的。不是给你们宫廷填表用的空。”

“建议另谋生计。”陈空把那句院里的话背出来，背得很完整，“三次。”

“三次还活着，说明你不是生计。”女人说，“说明有人把你当洞用。”

冰刃的刀尖从自己心口挪开，挪到女人喉前三寸。“再说洞，我让你变成井。”

“刃。”白昼只叫一个字。

冰刃骂了一声，刀仍不入鞘，只是偏了偏，偏成警告而不是立刻见血。

女人并不生气。她从腰后取出两支细瓶。瓶是潮都玻璃，薄，里面的水比刚才的净水更静，静得几乎能照见陈空那张被画胖之前的瘦脸。

“一支洗伤。一支喝。喝的那支别兑井水。”她把瓶子放在陈空掌心，放得很稳，“逃奴也要活着逃。死在井沿，宫廷会当疫报上去。疫会连坐到我。”

陈空握住瓶。瓶壁凉，凉过她的手。他想问宫廷是什么。问出口的是：“你叫什么。”

女人沉默。

井风把她青潮长发吹到身前，她随手拨到耳后。耳后有一粒很小的潮纹，纹是旁支的，不亮，像故意把光藏起来。

“你记名字。”她说，不是问。

“会。”陈空说。

“那就先别记我的。”她说，“记了，金契院问你，你会说。你会说真话。真话在这种地方等于把人往井里推。”

陈空把那句话咽下去。咽下去的感觉像咽糊粥，糙，却能活。他点头。点头不是答应忘记，是答应现在不问。

冰刃却不吃这套。“她叫潮汐。”冰刃说，刀指井里那一层一层的拍，“看她的手。祭司的手。潮都旁支跑出来当药罐子的，我见过残骸。残骸还戴着铃。”

女人看冰刃。第一次把对方当成对等的东西，而不是病人旁边多出来的刀。

“你见过的是被抽干的。”她说，“我还没有。所以我还在走路。”

井栏上的盐被刀磕下来，磕在陈空靴边，细碎，像谁把“逃奴”两个字又洒了一遍。陈空用没伤的那只手把盐拨开。拨开不是因为脏。是因为他不想让潮汐看见自己把这两个字踩进泥里——踩了，像在否认她的诊断。否认要有力气。他的力气还在左肩上漏。

“潮汐祭司。”白昼的声音放平，像把一个旧档案从记忆里抽出来，不打开，只确认封面，“光庭的边注里写过：潮都旁支善治，不善拒。不善拒的人会被当成井。”

女人没否认。

白昼把盾面微微转向井口，挡开一股忽然翻上来的湿。凹痕里又积了一点雾水。她不倒。倒了，雾水会滴到陈空纱上。

“两支怎么分。”白昼问，问的是规矩，也是怕陈空又把两支都让出去。

“一支伤，一支喉。”潮汐说，“别学他。他会把喝的那支也倒给别人。”

陈空把两支净水放进背包最不容易碎的夹层，和火柴盒隔开，怕碰。他动作慢，慢里有珍惜。珍惜让冰刃烦。

瓶在夹层里轻轻一碰，响得很细。细响让他想起糖纸。糖纸也细。细的东西在废都反而活得久，因为没人觉得值得抢。

“你对谁都这样。”冰刃说，“给糖的小孩，给粥的掮客，给两瓶水的陌生人。你空，空得像要把全世界装进去。”

“装不下。”陈空说，“所以只装现在。”

潮汐——他在心里还是把这三个字放下了，轻轻的，像放下碗——看着他左肩。纱是干的，干下面仍有热。她又从袖里摸出一小包药粉，药粉有海的咸。

“晚上若发热，用净水化开，敷。别喝井里的。”她重复，“井会让你梦见别人的死。你这种人梦见一次，就会想把所有死都捡回去。”

陈空低头：“我捡不回去。”

“所以别喝。”

拾荒者在石坪上翻了个身，嘴里还残留着蓝沫的气味。潮汐把那人的头侧正，又把陈空撕剩的、已经脏了的披风布角垫在他脸下，免得唾液淹住鼻。她做这些时仍冷淡。冷淡不是狠。是把心从手上拿开，手才能稳。

白昼忽然问：“宫廷会来？”

潮汐的手指顿了一顿。

井的南风里，极远，极细，有一声铃。铃不是废都的。废都的铃是铁，哑。那一声润，圆，像有人把水滴进铜碗。

潮汐把袖口的湿用手掌抹掉。抹不掉。她站直，青潮长发贴在颊边，像一条不肯断的河。

“会。”她说，“联姻的铃。药库也要回柜。”

冰刃听懂了“药库”两个字，脸上的笑没有温度。“他们叫你药库？”

“叫旁支。叫祭司。叫能治的那一只手。”潮汐看着自己的手，手仍凉，“叫什么都可以。只要还在用。”

陈空想说：你可以不用。话到嘴边，变成：“这两支……我能分给她吗？”他指了指睡过去的拾荒者。

潮汐看他。看了很久。久到冰刃都要不耐烦地用刀敲栏。

“你肩还在漏。”潮汐说。

“漏得少了。”陈空说，“他没有。”

潮汐把已经给出去的两支净水从他手里抽回一支，又放回去。抽回的是动作，放回的是决定。她没有再抽。

“随你。”她说，“你这种逃奴，最不会把水喝完。”

陈空“嗯”了一声。他听出逃奴两个字里的刺，也听出刺下面那一点说不清的、像水一样的东西。他不辩。辩不会让瓶子更满。

白昼把盾沿转向铃来的方向。凹痕对着南风，像一只听的耳。

“铃还远。”她报时一样报距离。

“远也会到。”潮汐说。

井潮拍上来，盐粒打在陈空包扎的左肩上，细细的，像有人用针提醒他：你还活着，活着就会被叫成各种名字。逃奴。空契。非法。废。

他都应。应完，把净水瓶又往夹层里塞了塞。

拾荒者在梦里喊了一声编号。编号含糊，像从井水里捞出来的。陈空下意识纠正：“你没有编号。”人听不见。潮汐听见了。她看陈空的眼神复杂了一瞬，复杂里有药，有柜，有一点她自己都不会承认的动摇。

动摇很快被铃压平。

井盐又落。落在瓶上，发出极细的响。细响像铃的亲戚。

宫廷的铃在更远的风里响了第二下。这一下更润，更圆，像催人回去，也像在井沿上轻轻画了一条不该被跨过的线。陈空听着，把“逃奴”和“契主”两张纸在心里对折，折完仍是空。空着，瓶还在掌心。
