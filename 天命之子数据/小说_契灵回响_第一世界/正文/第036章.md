# 第36章 跳车

冰刃先跳。

她不回头。刀横在身前，人像一截被扔出去的亮。风把她银白的短发掀直，布套在刀柄上翻成一只难看的蝴蝶。她砸进桥洞侧面的黑里，沙响，铁响，人响。然后是一声骂，骂的是地，也骂给后面听。

“空——！”

陈空听见自己的名字。不是编号。名字落在风里，像钉子。

白昼的手臂已经箍住他的腰。盾还在身后挡最后一点碎光。她没有问他怕不怕。问了也来不及。她只说：“闭气。落地别用手撑。肩会裂。”

陈空想说好。嘴刚张，世界就翻了。

他被扔出去。

扔这个字很准确。白昼的力从盾传到臂，从臂传到他这具又瘦又轻的身体，像把一件不肯自己走的行李送出车门。他在空中旋转。旋转时看见轨木一根一根往后退，看见冰刃落地扬起的沙，看见自己的膝盖、自己的肩、自己那只还扣着铁皮锈的手。手松开。锈留在掌纹里。风灌进领口，灌进左肩那道旧伤，灌进眼睛。他看见列车的犁齿在头顶划过，火星像一串不肯熄的牙。他看见自己的背包带子在脸前抽打。他看见白昼随即跟着跃出，盾翻成一片短暂的屋顶，替他挡了一块飞来的铁皮。

铁皮擦着盾面尖叫。尖叫里他想：她又挡。她总是先挡。他该说谢谢。谢谢在风里发不出声。

然后是沙。

沙不是软的。沙是结块的锈，是轨渣，是有人把废都的牙咬碎了铺在地上。他肩先着。左肩。那道被流矢擦过的旧伤像门被踹开，热一下子涌出来。他没叫。不是勇敢。是气被撞没了。

滚。

滚的时候他仍抱着背包。铁勺撞火柴，火柴撞那半块硬面包。面包碎了一角。他脑子里第一句不是疼，是：别把吃的弄没。

冰刃的手抓住他领口，把他从沙里拖起来。拖得很凶。凶完她看见他肩，骂声卡住，又换成更凶的：“蠢货。谁让你肩着地。”

陈空喘。喘出一口铁锈味。他说：“她说……别用手撑。”

“她没说用伤撑！”

白昼落地。盾插入沙里，人跪下来，先把盾沿转到三人外侧。列车从桥洞里吼过去，犁齿削掉洞顶一层砖，砖雨砸在盾面上，咚咚咚。她的脸颊还在渗那道浅红。她看陈空的肩，看了一眼，手已经撕自己披风的边。

“对不起。”陈空说。

“对不起的是扔你的人。”白昼说。她顿了一顿，又补，“我是扔你的人。所以我包。别动。”

布压上去。疼。陈空的手指抓紧沙。沙从指缝漏。冰刃蹲在旁边，刀尖抵地，布套上沾满灰。她不看包扎。她看洞口。列车的尾灯把洞口烧成一条逃掉的红，红里有金徽，金徽里有人回头。回头的人没下车。车还要赶去别处清场。顾衡的名字被风带走，只留下一股热铁的气味。

肩伤裂了。裂得比当初那道擦伤更深。血把白昼的披风边吃成暗色。陈空看着那块布，忽然想起自己唯一的干净衬衫。衬衫在冰刃小臂上。披风在他肩上。他们的衣服一直在别人身上。他想说别撕了。披风也所剩无几。话到嘴边变成一口沙。他吐沙。吐完，白昼把结打好，打得很死。

“能走十步就算能走。”她说，“十步后我再问。”

陈空走了十步。第十一步时膝软。冰刃的肩撞过来，撞的是右边。右边没伤。他记住了。她没看他。她看桥洞外会不会调头。列车的碾声远了，远成一条还在发热的线。线的尽头有金徽。金徽没有下来。下来要停。停会误清场的时辰。借名的人比本人更赶。

“能走吗。”冰刃问。问完又骂，“问也是走。不走等他们调头。”

陈空点头。站起来时眼前黑了一下。白昼的盾从侧面托住他的右臂，不托伤处。冰刃走在前面，踩沙，踩出一条浅坑。三人离开桥洞，钻进更窄的暗隧。暗隧的壁上有旧的编号漆，漆剥了，号码缺齿。陈空经过时下意识想纠正：那不是名字。纠正给谁听呢。壁不会答。

暗隧里风小。小风更冷。血的热变成黏。陈空用没受伤的手按着包扎，按的力很笨，像按一块漏的锅。

“别按那么死。”冰刃头也不回，“你要给自己按晕。”

“好。”

“你就会这一句。”

“……疼。”他补了一句。很小。像怕浪费她的耳朵。

冰刃的步子乱了一拍。乱完更稳。她把刀换到左手，右手向后，掌心朝上，不看他。陈空犹豫了一息，把自己的手搁上去。她的掌心有茧，有布套磨出来的热。她拽着他走。像拽一把不会自己出鞘的刀。

白昼在最后。盾擦着隧壁，发出细细的金属声。她报时。报得很轻：“后半夜。还有两刻天不会亮。亮了也不是给我们的。”

陈空听着。他数步。一步，两步，三十步。三十步一喘。喘的时候冰刃也不骂瘦了。不骂比骂更可怕。他想说自己能走。话到嘴边变成一口血味，又咽回去。

暗隧向下。向下的地方更黑。黑里有水声，不是井，是管漏。管漏滴在铁上，滴出一种像眨眼的节奏。壁上的编号漆越来越密，密成一排排缺齿的笑。陈空每经过一个缺号，都在心里补一句：她叫冰刃。他叫空。盾叫白昼。补完，漆不会改。他仍补。纠正是他会的。会的事在黑里也要做。

他们在暗隧里走了很久。久到陈空把三十步一喘又数了一遍。数的时候冰刃不骂瘦。不骂比骂沉。沉的刀走在前面，布套偶尔碰壁，闷响。闷响提醒他：裂还在。裂着仍开路。

白昼报时。报得很轻。轻到像怕把血惊出来。“还能走。走完这弯有避车洞。洞里能坐。坐了才能看肩。”

陈空想说肩不要紧。话到嘴边变成一口铁锈。他吐在壁上。壁把血吃进去，吃成一块很快变暗的斑。斑很丑。丑的东西他见多了。见多了仍会心疼布。布是白昼的披风边。披风边越来越少。少得像他的衣。

陈空忽然觉得脖子凉。

不是风。风在身后。凉是一条很细的、像锁链擦过皮肤的触。他抬手摸。什么都没有。锁链的触感却还在，像有人用一根不存在的绳子量过他的喉结，量完，笑了一下。

他停下。

“怎么。”冰刃回头。

陈空张嘴。他不知道该怎么说“有锁链，可没有锁链”。说出来像吓自己。他只说：“前面……有人。”

白昼的盾立刻抬高。冰刃的刀出鞘，布套摩擦。暗隧深处没有脚步。没有呼吸。只有管漏。滴。滴。

然后陈空看见了。

不是人。是眼睛。

隧道深处，比破灯更远的地方，有一双眼睛。笑着。笑意不达光，只达缝。像有人把夜本身眯起来，眯成两道弯。

冰刃的刀尖对着那双眼睛。

白昼把陈空往自己盾后带了半步。半步很短。短的是保护。保护的人自己露出半边肩。“别对视。”她说，“暗的眼睛吃对视。吃完会跟着走。跟着走就会变成锁。”

“它已经量过了。”陈空的声音发干，“量我的脖子。没有东西。可是凉。”

冰刃骂了一句很脏的话。脏完她把刀尖又送出去一寸。一寸里什么都切不到。切不到她仍切。切是给那双眼睛看：这空的人不是一个人。旁边有刀。刀裂了。裂了也能砍空气。

空气不流血。陈空把破灯又拧暗。暗了，那双弯着的眼睛反而更清楚。清楚不是近。是它不需要光。不需要光的东西在看他额上的空。空着，像一个还没被扣上的锁孔。锁孔发凉。凉着，他仍把冰刃的名字含在嘴里。含着，就不那么像一个人站在暗里。

管漏还在滴。滴声把那双弯着的眼睛衬得更像活的。活的东西不说话。不说话比说话冷。冷贴着陈空刚被量过的喉结，贴出一层细汗。汗里他仍站着。站着，是因为冰刃的肩在他前面。前面有刀。刀对着空。空对着笑。

眼睛不眨。
