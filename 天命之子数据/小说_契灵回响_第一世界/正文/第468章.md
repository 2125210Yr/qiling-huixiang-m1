# 第468章 打太阳

第一刀是冰刃的。

她从不需要号令。刀光起时井心一暗，暗只一眨眼，太阳又亮。刀锋从光的中心剖开，剖出一道黑缝。黑缝里有奶香漏出来，漏完，缝自己长上。长上的地方更亮，亮得像嘲笑刀。

冰刃第二刀改砍自己脚前的井石。石屑溅到光上，光把石屑烧成金沙。她吐一口：“砍不进就砍你站的地。”地也不肯塌。

“别砍地。”陈空喊，“井要是塌，大家都在里面。”

“那你想个不塌的办法！”冰刃头也不回。刀上奶香让她皱眉。皱眉仍砍。

陈空没有办法。他不会阵。不会克制。火克木，木克水，水克火，光暗互克，克的是契灵交手。太阳不受属。他也不受属。两个不受属的东西对上，像两口空锅对撞。撞不出饭。他只会喊名字。他把名单从心里过一遍，过到嗓子干。过的时候还是那张一路记下来的纸。纸被射穿过。森语背过。白昼背过。最后人人会背一点。此刻他仍自己喊。自己喊才像门闩还在他手里。

“刃——盾——潮——影——路——卫——咒——医——旗——浪——闸——锚——镜——箭——墙——棘——苔——锋——闪——露——歌——夜——壁——幕——语——”

二十五声被他喊全。喊全的时候他咳血。血很浅，浅到潮汐看一眼就知道是嗓子，不是肺。她把净水递到他唇边。他喝一口，继续喊。喊不是指挥。喊是把门闩一个个报给门。

白昼以盾撞日。

盾面凹痕叠凹痕，反光碎成许多小太阳，小太阳仍要往陈空额上飞。她把盾转横，当门板，把门板死死抵在光前。脚在井石上犁出两道白印。旧伤在她肩胛里响。陈空听见那响，像生锈的弦。他想去撑盾沿。白昼用肘把他肘开。

“你的手撑不住这个。”她说，“你喊我就行。”

潮汐、炉灰、青苔、晨露、夜幕五道治力缠上白昼的肩。肩不塌。太阳却从盾顶溢下来，溢成一条要贴额的舌。

裂潮刃与夜刃对切。一浪一短，切成十字。十字在光上开花，花是金的，金的花心里仍是那张婴儿脸。冰镜使者把裂掉的镜子碎片抛上去，碎片照见二十五个人的不愿意。不愿意叠在一起，光晃了晃。晃完复原。

熔渣咒印终于把脏话骂成咒。咒火是黑的，黑火咬太阳的边，咬下一块，一块在空中又圆回来。她气得蹲下，抓井水洗嘴：“我骂炉芯都能骂裂。这玩意儿没耳！”

毒棘使又撒了一次痒粉。太阳仍不抓脸。她转向编制方向，编制阵脚立刻乱了半排。陈空急了：“别痒自己人——他们也有名字。”

“那给太阳起名啊。”毒棘使说。

陈空看着那光。光漂亮。光香。光要填他。他摇头。

“它不叫太阳。”他说，“它是抽走的东西。抽走的……不是我。”

低语引把这句耳语送进所有人耳朵。耳语比喊快。二十五人的攻势忽然齐。齐不是编制那种齐。齐是同一种不愿意。火的热不往陈空身上靠，往光上靠。水的潮要把它灌灭。木的根要把它绑出井。光属的人最难受——打光像打自己的姐妹。昼锋的牙咬出声，仍劈。劈完说：“条例里没有强迫回家。”

眩光缚闪瞎了太阳一瞬。一瞬里影壁把墙叠到最高。最高处夜幕医师抛下一片黑纱，纱要盖日。纱燃了。燃的味道像残灯回廊的油。

打了很久。久到陈空的膝盖软。久到顾衡又吐一次血，仍站在司衡和阵之间。久到司衡不再按阵，只看着，看着自己的算术在光里自己动手。

编制的弩放不下。放不下又射不出。射出会穿过契灵，穿过太阳，最后仍可能射中圈心那个废材。废材正被二十五个人护着。护着仍喊。喊到后来只剩下气。气里全是铁味。铁味让他想起浊潮井。井水喝多了会梦见别人的死。此刻不用喝。太阳自己把别人的生送进来。生是他的。生被抽走过。抽走的要回家。回家的路被刀、盾、水、锁、叶砍得乱七八糟，仍在。

灼红侍从的旗被烤出焦边。焦边她不换。不换是因为旗是信号。信号在广场上用过。用过的旗现在对太阳摇。摇的意思是：这边不收。不收的货请回仓。仓在婴儿的井里。井该熄。熄还早。早的是打。打得越响，光碎得越圆。

太阳碎过。碎成十七块，像十七岁。碎成二十五块，像二十五个人。碎完每一块都是完整的太阳，完整地朝陈空的额飞。白昼左挡右挡，挡到盾面像被锤过的锅。冰刃砍到刀鸣变哑。潮汐的唇血把下巴染红。影缚者的锁收回来，锁上没有猎物，只有烫。

森语停手。

她很少在战里停。停是因为她听懂了。根在光里找不到土。找不到土的东西，不是能被砍死的树。

“打不碎。”她说，轻，方向很死，“它要空契自己不认。我们是客。客赶不走主人不肯赶的影子。”

井心一静。

冰刃还想砍。白昼按住她的腕。按得很重。冰刃骂：“按我干什么！”

“按你，是让他说话。”白昼说。

所有人回头。

陈空站在圈心。补丁衣被光晒得发白。围巾松了，影缚者没来得及勒。潮冠在他背包外侧轻轻碰铁勺，叮当一声，像提醒他还带着一只碗。他的额空着。空的上面却覆着一层细金，细金是太阳留下的膜，膜在往里钻。

他抬手。不是去接。是去摸那层膜。膜烫。烫得像灌纹台的热铁。热铁当年要烫进他额心，冰刃咬开他虎口，用血把纹引走。此刻没有热铁。热铁成了太阳。太阳不要血引，要他自己点头。

陈空看冰刃。

冰刃不表态。这比骂更重。可她的刀在。刀在就是人在。人在就不搬——除非他吞。

陈空点了点头。点给她们。点给打不碎这件事。

“别打了。”他说，“打它，它会变成更多。我来不认。”

圈上的呼吸乱了一息。乱是因为他们听懂了。听懂比听命令慢。慢完冰刃把刀垂下去，垂得不甘。不甘她仍垂。垂的意思是：你说不认，就去不认。不认不是我们替你。替你就会又变成编制。

熔渣咒印骂：“你手无缚鸡——”

“我不是打。”陈空说，话仍慢，“我是否。”

白昼把盾沿让开一掌。一掌是路。路只够他走进光。走进去的人背包还在。背包外侧潮冠碰铁勺。叮当。叮当像提醒：去否的时候，把吃饭的带着。吃饭的人才能回来。回来才有粥。粥会糊。糊也要有人喝。

太阳听见“否”字，忽然全体合回一颗。合得又圆又近，近到陈空的睫毛被烤得发干。它把香气全部压进他鼻腔。压进的意思是：你看，她们打不碎我。你只能要我。

陈空的双手垂在身体两侧。虎口牙印对着光。牙印像一张旧的嘴，替冰刃先说了不。

他走进光里。

走之前他把围巾松了松。松给影缚者看：门自己出去一趟。看门的别跟进胃。影缚者骂了一句很短的。短完仍站在圈上。站是信他。信他会不认。不认才配让锁留在外面。

圈上有人要拉他。白昼先动，又停。停是因为陈空回头看了她一眼。那一眼说：挡，但别挡我自己的额。冰刃没有停。冰刃跟了半步。半步被陈空用名字喊住。“刃。”一声。一声她站住。站住比砍更难。难的刀尖朝下，朝下仍抖。抖是怕他认。怕他认她就得搬。搬的话她说过。说过就要作数。作数的人把后背交给他。后背交给圈。圈交给空。空走进光。

光吞没他的肩。吞没围巾。吞没那块旧衬衫残布。井心只剩下一个黑瘦的影子，站在一颗不肯灭的太阳前面。

要他认。

或不认。认了就满。满了就搬。搬的路他不走。
