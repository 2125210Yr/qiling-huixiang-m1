# 第377章 认

“我认事。”陈空说。

四个字。字与字之间有缝。缝里是他想词的时间。想词的时候全场以为他要崩。崩了更好写。律师的笔已经抬起来，准备写“供认”。

“不认罪名。”他又说。

笔顿住。

白圈里的光像被谁拧了一下。拧完更亮。更亮也改变不了这两句的顺序。顺序是他排的。排得很慢。慢得像拾荒时把铁和粮分开：能吃的放左边，能伤人的放右边。事是左边。罪是右边别人贴上的签。签他不认。不认不是因为他会辩。他不会辩。他只会把东西放回原处。

昼律看着他。法冠如日。日不眨眼。

“说清楚。”她说。

圈外冰刃的刀柄又响。响是准他。准完白昼把盾沿再送近一寸。一寸光被切出一条暗。暗里他能看见自己的鞋。鞋有洞。洞里有白。白要从下往上听他。听他不利索。不利索也好。利索的嘴刚才属于律师。律师把五件事洗成五条罪。洗完很体面。体面他学不会。学不会就慢。慢把铁和粮分开。分开要呼吸。呼吸时花粉又动。

陈空点头。点头时花粉又动。他用手背堵住鼻子，堵住的样子难看。难看也要说。说不利索。不利索是他的本钱。本钱在金契院试场用过三次，用出三张空。空现在要当嘴。嘴先干。干是盐。盐还在牙缝里。牙缝帮他把第一句咬住，咬住才不会跑去道歉。道歉他们会当认。认的是事。事要从第一件数。

“第一件。”他数。数是他会的。十七岁，左数第七个，三十步一喘，火柴三根。数得清的东西不会骗他，“我额上没有纹。她们愿意住。我没有填。没有扩。是空着。空着才住得下。住得下不是我抢。是她们选。”

律师要插。昼律的手指在案沿点了一下。一下。律师的袍子金边晃了晃，仍站着，暂不说话。点是给被告的。给得很短。短的意思是：继续。别指望长。

“第二件。聚。人走在一起叫聚。我不懂一主一契。我只懂她们不愿意被分成一半。不愿意的，我不递。回收令我见过。我非法。我自己亮过鉴定书。冰刃把书抢回去叠好。叠好的书还在。”他把贴身口袋按了一下。纸角扎人。扎完他继续。

“第三件。关炉。关了。停电。老人死。我知道。门板拆了给他们烧。粥糊了。他们骂。骂完喝。炉芯说宁可黑，不愿甜。甜是因为烧过名字。名字不该当柴。这件事我做了。做了有人冻。冻是真的。真的我认。认完我仍会关。再有炉烧人，还关。”

说到冻，他停了一下。停是因为顾衡问过那句：你知道死了多少老人吗。知道。数字对不上。心对上一点。这一点在庭上不像辩。像把死人又搬出来。搬出来不是为了甩锅。是不让起诉书把死人只写成他的刀。刀不在他手里。手里当时只有拆下来的门板。门板沉。沉他搬得动。搬得动的人不会契术。不会就把暖改成柴。柴不甜。不甜的黑里有人骂他。骂完仍靠那点暖活过一夜。一夜写不进法。法要停电。停电两个字干净。干净盖不住糊锅。糊锅他承认。承认完把第四件从喉咙里拽出来。拽的时候嗓子哑。哑是一路喊名字喊过。喊过的哑在白圈里更清楚。

看台有人站起来。站起来被执庭卫按下去。按下去的声音像鼓的边。边不入律。律仍听得见。

陈空的耳朵热。热不是羞愧。是他不习惯一次说这么多。这么多里没有一句像辩。辩要锋。锋在冰刃那儿。他这儿只有慢。慢把第三件拖得很长。长到他自己都听见喉结响。响完，第四件。

“抗婚。不是我抗。是潮汐不当药库，不当新娘。婚契她撕了。冠……冠是她扣我手里的。我翻过来。能盛汤。汤是热的。伤员在。我盛了。潮后骂荒唐。骂完把汤舀进那只碗。碗还在包上。你们当国宝。国宝能盛汤。盛汤不是辱。是用。”

潮都文书官的脸白了一度。白在光庭不稀奇。稀奇的是白里有红。红像被那句“舀”烫到。烫到的人没有说话。说话权在律师。律师的嘴角已经不是浅了。浅变成笑。笑还没出声。出声是下一章的事。陈空看不见那么远。他只看见自己的鞋。鞋有洞。洞里有光。光要从下往上审他。

“第五件。锁库。我进了。门上写空契入，勿出。我入了。出了。影缚者没有勒死我。她把锁织成围巾。围巾在。锁库后来淹了。水是记忆。潮汐开路。我拉过一个掉队的人。人说谢谢编号。我纠正。他没有编号。纠正也是我做的。做的我认。”

他说到这儿停住。停住是因为词用完了。用完的词在白圈里打转，打转成一些不齐的句子。不齐的句子没有结尾。结尾他想了想，补上：

“事我都做了。罪的名字是你们起的。起的名字我不认。认了，她们就变成我的凶器。她们不是。”

说到凶器，他看了一眼圈外的刀。刀入鞘。入鞘仍饿。饿的不是要砍他。是要砍笑。笑还没出声。出声是律师的事。他的事说完了。说完嗓子哑。哑里还有第五件的锁库、纠正、围巾。围巾在脖子上。脖子被日照得发烫。烫不是勒。勒过的人还在喘气。喘气他把最后一口气用在这几句上。几句不齐。不齐像拾荒篮。篮里有铁，有粮，有布。布是衬衫。衬衫不在。在的是补丁。补丁被全场看。看完他们会笑。笑之前他先把名字放回原处：她们有名字。名字不是编号。编号是回收令上的。回收令他见过。见过仍非法。非法他认。认非法不等于认她们是他的刀。刀是冰刃自己。盾是白昼自己。水是潮汐自己。锁是影缚者自己拆的。路是森语自己认的。自己的东西他不占。不占才住得下。住得下被写成聚。聚他认。聚的名他不认。

全场静了两息。两息是给迟钝的纹留的面子。纹不迟钝。迟钝的是他的嘴。嘴还想说。说不出来。说不出来的部分他咽回去。咽回去比说出来干净。干净的空里只剩站。站着等下一句从起诉席上来。来的大概是笑。笑他接得住。接不住也要站。站是他会的。会的事情不多。不多就要做完。

昼律的笔动了。动得很慢。慢得像把“认事不认罪”六个字写进法，写进法就会脏法，脏了仍要写。写完她抬眼。

“被告口齿不利。记录如实。起诉人可问。”

律师的金边亮了一下。亮完，他笑了。笑得很轻。轻得像怕弄脏地板。地板是白石。白石不怕脏。怕脏的是体面。体面的笑先到达看台，看台接住，接住就放大。放大的时候陈空还站着。站着的废材不会辩。不会辩的人最好笑。最好笑的人最适合当庭上的例子。例子要给所有空格子的孩子看：空了，就这样。

冰刃的刀已经出鞘一寸。一寸在光里像一条细细的冰。冰指向庭柱。庭柱很粗。粗的东西她砍过。砍过的人现在被白昼的手按住。按住是后话。这一刻，律师的笑先落地。落地像一粒盐。盐进了陈空的牙缝。牙缝里本来就有。有了更多。更多他仍咽。

他知道自己说不利索。不利索也说了。说了就站着。站着等笑。等笑比等箭难。箭至少有方向。笑从四面来。四面都是白。白里他仍把那两句按在牙上：认事。不认罪名。按住才不会被笑冲走。冲走的词捡不回来。捡不回来她们就会被写成他的刀。刀不是他的。他空着。空着站。站到笑落地。落地也要站。站着的空还在。在，才轮得到下一声笑。
