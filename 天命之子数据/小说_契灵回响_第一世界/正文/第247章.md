# 第247章 下层风

风是吸的。

陈空第一下以为是自己走得太慢，慢到被后面的人推。后面没有人推。后面的灰围裙抓着石壁。石壁的灰往前走，往城门牙里走，往一条看不见的喉走。灰都会走。人更会。

围巾先飞。

暗红的锁链织纹被拉直，拉成一条要回家的蛇。家在后面，也在下面。下面更像家。家会勒。勒过他，才知道勒不住。此刻它像要先把他勒给胃看：看，门上有锁。锁是包装。包装好的空契更好吞。

影缚者的手按上他的领。

按得很急。急得不像笑话。黑发被吸风掀开，露出半张一向藏着的脸。脸上没有笑。没有笑的影缚者像一把没讲完的锁。

“低头。”她说，“别把额送给它。额空，空会发光。发光就是招手。”

陈空低头。

下巴抵进围巾。围巾还在往后。往后的力道从暖变成拽。拽得他脚下一滑。滑的时候白昼的盾沿已经抵住他后腰。抵住不是抱。是把门框装在人身上。

“站稳。”白昼说。先挡。挡完才解释，“风不打人。风数人。数到空，就会加力。”

冰刃把刀横在风口。刀刃上的光被吸弯。弯了一下，又直。直的刀骂：“吸你的。吸不动的东西多了。”

刀是吸不动的。刀有锋。锋会把风切开。切开的风从两侧走，走成两股更细的饿。细饿专找缝。缝在陈空的领口、袖口、鞋底的洞。洞里往外漏热。热被抢走。抢走以后，他的牙齿开始打。

潮汐把掌心贴上他后颈。掌心凉。凉在吸风里像一枚不肯走的钉子。钉子稳住他的呼吸。呼吸一稳，围巾的力道就小半寸。小半寸够影缚者把线头绕回他喉下，绕成一个不会勒死、也不会被整条抽走的结。

“结是我的。”影缚者说，“谁抽，抽到我。抽到我，我会笑话它消化不良。”

熔渣咒印把脏话改成咒。咒很脏。脏咒在吸风里散得快。散得快也能让风口浊一下。浊一下，炉心卫士便侧身，用甲面把风口的最中心挡住。甲面发响。响像炉壁被抽空。抽空的炉她见过。见过她还站着。站着的甲是门。门可以不是陈空一个人。

森语把叶子从头发里摘下来。叶子一脱手，就往下飞，飞成一条绿的线。线指出风的真方向：不是后，是下。下在台阶尽处。尽处有一道黑。黑里有红。红还没亮透。亮透就是灯。灯若是红的，便不是给人看路。是给胃看食。

“到口了。”森语说。

口不是门扇。是城门地基裂开的一条缝。缝宽够一人侧身。侧身的人会擦到两边的刻字。刻字密。密成一层层被磨过的编号，编号上覆盖新漆。新漆写：守核下层。守核下层六个字金得发腻。腻是甜。甜是饿。

陈空被吸得往缝里倾。

倾的时候他抓住石棱。石棱割开茧。茧裂，血出来。血一出来，风更欢。欢得像尝到汤。汤很少。很少也是第一口。

熔渣咒印把脏话改成对着缝喊。喊的是“吐出来”。吐出来三个字在吸风里被扯扁，扁成一声很脏的哨。哨没有用。没用她就解下自己腰上的脏绳，脏绳一头塞给炉心卫士，一头绕过陈空的腰。绕不是绑囚。是怕门被风先请进去。请进去的空契叫自愿。自愿的报告最好看。好看的字她用脏话挡。挡不住风，能挡一点体面。体面在这里是毒。

“勒紧。”炉心卫士说。铁甲里的声被风撕开，撕开仍够命令。命令给绳，不给陈空。陈空若被命令，命令会像编制。编制他不会。他只会被绕。绕着他点头。点头时围巾仍往后飞。飞的方向和绳相反。相反的两股力把他夹在中间。中间疼。疼说明还没被吸成一条。一条就没有中间了。

森语把第二片叶子扔进缝。叶子不往上。往下，往下，快得像被一只看不见的筷夹走。筷在胃里。胃在练习夹菜。菜若是人，人最好先学会低头。低头的额少发光。少发光，筷会慢半拍。半拍够白昼把盾再插深一寸。

“别出血。”炉灰医师的声音第一次高，“血是香的。香会让它把你当开胃。开胃过，正餐就到。正餐是你整个人。整个人不好缝。不好缝的伤，我在炉心见过。见过就知道：先按住。按住比骂风有用。”

冰刃已经把陈空的手抓过去，用自己的衣角按住。按得很凶。凶完她把那点血擦在自己刀柄缠布上。“吸我的。我的血不好喝。喝过崩契的，都会嫌。”

风真的偏了一偏。偏完更恨。恨从缝里变成一声很低的鸣。鸣不像兽。像有人把无数格子同时合上。合上的空响，空响打在陈空额上。额仍空白。空白被打一下，便发热。热不是纹。是被看见。

被看见的感觉他熟。试场的灯白过。鉴定师的章红过。全场笑过。笑是一种看。这种看更安静。安静的看像称。称完，写上重量：可食。

他想吐。吐会被吸进去。吸进去的吐也是供能。他便把吐咽回去。咽回去糖膜还在。糖膜甜。甜和饿撞在一起，撞得他眼黑。

白昼把盾插进缝。盾面朝外，凹痕朝里。朝里的意思是：凹也可以当窝。窝里能站住一个人。一个人是陈空。陈空被她按进凹后，风从盾两侧走。走的时候发出金属的哭。哭是盾在扛。扛过弩的盾，现在扛饿。

“进不进。”冰刃问。问他。不问风。

陈空的领被影缚者按着。按着的手指在抖。抖不是怕他自己。是怕锁链织成的围巾被认回去。认回去，她又会变成锁。锁的任务是把空契按进仓。仓在下面。下面很近。

“进。”陈空说。

进字哑。哑仍够。够把怕变成方向。方向一有，吸风反而像路。路很坏。坏路也是路。森语认路。路认空。空便侧身。侧身的时候，他最后看了一眼台阶上面。上面很远。远得旗已经看不见。看不见不等于没有。没有的东西才叫灭。不灭的旗会在土里继续敬礼。敬礼的手臂也许已经麻了。麻了还在。还在就行。

他们侧身入缝。

缝里的风更窄。窄风专勒脖子。影缚者把整个手掌贴在他领口，贴成一块人做的扣。扣很热。热是她的。她的热和胃的热不一样。胃的热要拿走。她的热要留下。留下的热让围巾暂时不飞。不飞的围巾仍向后扯。扯是提醒：口在后，也在前。前是更深处。深处有底座。底座上也许有榜。榜上有格子。格子会亮。

陈空的额很烫。

烫得他想起灌纹台。台也很烫。烫的时候有香。香像终于能保护谁。冰刃咬开他的手。血把纹引走。引走以后，他空着。空着才住得下。现在烫又来了。来的方式不是灌。是吸。吸要把空本身抽走。抽走空，门就没有了。没有门，胃就可以关门细嚼。

他按住自己的额。按住一块什么都没有的皮。皮下面是骨。骨下面是他。他很薄。薄的人最好做门。门要开着。开着就会漏。漏对胃是亏。亏让他活。

“还在？”影缚者问。问的是人，不是围巾。

“在。”他说。

在字被吸扁。扁了也能认。认完，她才把按在领上的手松半寸。半寸里围巾跳了一下，跳完又被她按回去。按回去的力道像一句没说圆的冷笑话：看门的可以怕。怕完仍按着。

缝的尽头亮了一点。

一点红。红得像有人把血装进灯里。灯还远。远的红已经在墙上爬。爬成许多细格子。格子空着的地方更亮。更亮的空像在笑。

风忽然小了。

小不是饱。是它把他们让进嘴里。嘴里会安静一会儿。安静是礼。礼给食材。食材要自己走完最后几步。走完，才好吃。

陈空听见自己的心跳。一下。一下。像拾荒时敲锈铁。锈铁有时会空响。空响此刻很适合当门环。

他伸出手。手还在出血。血被他自己的衣角按着。按着也要伸。伸是去摸前方那块已经能碰到的壁。壁热。热壁上有字。字他摸到了半个：榜。

榜字下面，风完全停了一停。

停的时候，影缚者仍按着他的领。按着，像怕风只是在换气。
