# 第104章 空地

稍宽的空是一块根盘。

根盘像一张被年轮撑开的桌子。桌子上没有碗。没有碗也能坐。坐下去之前森语先用脚试了试。试完她点头。点头，刺从四周退到一臂外。一臂是说话的距离。说话的距离里，白昼仍把盾放在能挡的位置。挡是习惯。习惯不针对林。针对林外那十二个人可能的火。

陈空坐下。坐下时掌心的叶子仍平着。平着像托。托久了手会酸。酸他换左手。换的时候叶子边齿刮过牙印的布结。刮得很轻。轻得像问疼不疼。

森语看着那圈布。“谁咬的。”

“我。”冰刃说。第三次有人问，她答得更干脆，“有人要把字写他额上。字会占房。占房我咬。”

森语点头。点头不像赞。像记录。记录完她坐到陈空对面。对面刚好一棵小棘的阴影。阴影里她的叶子头发更绿。

“种子认空。”她说。

陈空等。等完整。完整的话她说得很慢，慢到像怕说快了土地会听错。

“有主的地不长新的。主把汁液都签了名。签了名的汁液只养旧根。旧根是编制。编制很齐。齐了就没有缝。没有缝，种子进不去。进去也会被当成病。病要被锄。”

冰刃插嘴：“所以金契院是旧根。”

“金契院是铁旧根。”森语不反驳，“林自己也有旧根。旧根不一定坏。旧根会挡风。挡风的时候也会挡新的。新的要空地。空地不是没人要。是还没被写成谁的。”

陈空听着。听着他把叶子又放平一点。放平是因为听懂了“不占”。不占他会。拾荒行里最后一块面包他不先拿。不先拿等到别人说不要。不要了才捡。捡不是抢。抢是占。占了别人嘴里就空。嘴里空比手里空难受。

他不懂农。不懂什么时候下种，不懂哪块地要歇。拾荒场的土只长锈。锈不是苗。苗要空。空的道理他从粥里学过。粥少的时候，碗要先空给别人。空给别人，自己那份更糊。更糊也能刮。刮完锅底，锅还空。空的锅明天还能煮。煮的人如果把锅据为己有，据为己有的锅就只剩一个人的名字。一个人的名字装不下四张嘴。现在是五张。五张嘴要并排。并排就要有人把锅留着不当自己的剑。

“有主的地不长新的。”他重复。重复得很慢，“我额上要是被写成主，你们就变成旧根。旧根会挡风。挡风也会挡新来的。新来的就没处发芽。”

森语点头。点头像看见种子自己把壳啄开了一条缝。“你不懂农。懂空。懂空比懂农难。懂农的人会插旗。插旗的人把地量成亩。亩有主。主有契。契有纹。纹一亮，种子就当自己是病。病要被锄。锄完地很齐。齐了就不长。不长的地金契院最喜欢。喜欢拿去开路。开路去追空的人。空的人如果自己也去当主，林就没必要让。”

“我不懂农。”他老实，“不懂种。懂不占。不占就是……这片叶子我托着。托着不是我的。是它愿意停。愿意停我才不停手。”

森语看他。

看了很久。久到影缚者都把脑袋靠上他肩，靠着讲：“空地讲话像说明书。说明书我喜欢。喜欢短的。短的是：他不收房租。不收房租的地，草才肯长。”

“你是草？”冰刃问。

“我是霉。”影缚者说，“霉也要空房子。满房子的霉会被扫。”

潮汐把水壶放在根盘上。放的位置不占路。不占路她才安心。“你说空地。空地能带路吗。带路要不要契。”

森语的手指在自己掌心划了一下。划过的地方没有金契院那种纹。有一圈浅浅的木纹，木纹像年轮的缩写。缩写会亮。亮不亮看她愿不愿。

“契是双方。”她说，“我给人带过路。带过有纹的。有纹的人走着走着就把路当成自己的。当成自己的就会插旗。插旗的路会死。死路过一次，我不再给有纹的人带。”

白昼问：“他没有纹。我们有契。我们算有纹的人吗。”

“你们的纹在他空里。”森语说，“空里的纹不插旗。不插旗，林可以再看。再看需要时间。时间里我可以走在前面。走在前面不是他的刀。是他的路。路可以离开。离开前先问空地一句。”

她把那句话问出来。问得很轻。轻，方向仍死：

“你要我带吗。”

陈空没有立刻答。

不立刻是尊重。尊重选择。选择过冰刃、白昼、潮汐、影缚者。每一次他都问愿意还是没地方去。这一次对方先问他。问他要不要路。路不是工具。路有脾气。脾气慢。慢的脾气一旦给了方向，方向就死。死的方向他接不接得住，他要自己知道。

冰刃忽然开口。开口仍毒。“你带路可以。带路别把他养成树。树不会躲箭。不会躲的人已经够一个。”

“不当树。”森语说，“他是空地。空地不是土。土会把人埋。埋了叫占。空地让人过。过了还空。还空，种子才肯来。肯来不是他的收成。是林的。林的东西我不献给契主。契主如果问收成，我就不带。”

白昼点头。“他不问收成。他问愿不愿意。问完把粥分出去。分出去的人不会把你写成亩。”

影缚者打了个哈欠。哈欠很假。“我投空地。空地不收房租。不收房租的地方霉才肯长。长了我负责看门。看门不管发芽。发芽归你。你要是把路带到坑里，我把你的影子和坑底结上。结上你自己爬。”

潮汐把水壶往根盘中心推了推。推的位置不占叶。“喝。说话口干。口干路会岔。”

森语看了看壶。看了看陈空。看了看那圈牙印。牙印让她明白这空地是被咬回来的。咬回来的空比天生的空贵。贵的东西她问得更认真。

他知道自己不会打。

会打的人在他后面。后面四个人已经把房间住得像家。家还能再空一张席吗。席是位置。位置是他的废。废得干净，才配再请一个。请了，林会不会把他当成主。当成主，路会收回。收回会咬。咬到她们。咬到她们，这张席就白空了。白空浪费。浪费他怕。怕了就要把话说明。说明不是契约辞。是界。界在：路还是林的。他只走。走的时候不插旗。

“我不要把林变成我的。”陈空说。他说得很慢，每个字都像钉子，钉在根盘上，“你带路。路还是林的。我只是走。走的时候不插旗。不插旗，你随时可以不带。不带也告诉我一声。告诉了，我自己找缝。找缝会慢。慢也行。慢总比占好。”

森语的眼睛亮了一下。

亮不是金。是林隙里漏下来的那点天。天在她瞳里方了一下，方完又圆。圆的时候她把头发里一片还绿的叶子摘下来。摘下来没有放进他掌心。掌心已经有一片。两片就满。满了不像空。她把新叶子放在根盘上，放在两人中间。中间是契的位置。契的位置谁先碰，谁先表示愿意。

冰刃盯着那片叶子。“又要亮一下？”

“可能会。”森语说，“亮了就灭。灭了还在。在的东西叫同意。同意不是主仆。是空地肯让路从上面过。路肯把空地认成能发芽的地方。”

陈空看中间那片叶子。

看完他仍没有先碰。他看森语。看她头发里剩下的叶子。看她没有靴的脚。看她问过他之后把双手放在膝上。膝上的手是空的。空的手在等。等不是命令。等是请。

“我愿意。”陈空说。

森语点头。点头很轻。轻完她把右手伸过来。伸过来的掌心有土味。土味干净。干净得像还没被写成谁的。

潮汐忽然问：“契约亮的时候会不会疼。他手上有牙。牙还新。”

“疼在空里。”森语说，“空里能装疼。装了疼还空。还空才成。成了不是主仆。是我把方向借给他的额。额不写我。不写我，我才肯借。”

陈空把右手藏得更后。更后给牙印留地方。留地方不是瞒。是不让新契和旧牙叠在同一只手上。同一只手太满。满了不像空。不像空，叶子会走。走了中间那片还在根盘上。根盘上的风把它翻了翻。翻了仍在。在就是等。等他愿意。愿意已经说出口。出口之后只要碰。

根盘四周的刺轻轻响了一声。响不是咬。是把耳朵凑近。凑近听一扇空门会不会再开一条缝。
