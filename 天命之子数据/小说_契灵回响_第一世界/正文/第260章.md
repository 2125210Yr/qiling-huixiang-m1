# 第260章 算术不算名字

“算术不算名字。”

陈空说完，自己先愣了一下。

六个字。没有鼓。没有金。没有把三十七变成三十六的本事。他甚至把“算”字咬轻了，轻得像道歉。道歉是他的老毛病。被骂了会先道歉再想反驳，想完也不反驳。这一次他反驳了。反驳得不利索。不利索地立在机房中央，像一根插错位置的销。

投影里的司衡看着他。看的时间比看一份错误清单更长。长出来的那一点不是怒。怒会脏。他只是遗憾。遗憾一个本可以填进管口的空项，偏要在表外说话。

“再说一遍。”冰刃说。

她侧着脸。银白短发，左眼下旧裂。刀尖仍对着齿轮。她不看陈空。不看是让他的脸不必为这句话负责表情。表情会软。软了，金契院会当情绪。情绪好入账。

陈空咽一口。哑。再来。

“算术……”他顿，“不算。名字。”

顿得更乱。乱也是他说的。他说的就要站住。

机房里有人把呼吸放轻。放轻是怕把这六个字踩碎。碎了就只剩情绪。情绪司衡会收。收进“会过”那一栏。栏不能赢。赢要钉子。钉子已经钉出来了，歪，浅，可它在铁上。铁上的东西齿轮一时咬不掉。咬不掉就会响。响给所有还在转的齿听。

冰刃把这句话接过去。接过去的时候，刀在齿上划出一道白。白很细。细得像把六个字重新刻进铁里。她的声音比刀硬。

“算术不算名字。”她重复，狠，短，每个字都砍过一遍，“你听清。表听清。齿轮也听清。听不清我就把齿掰开，让它用断口听。”

白昼点头。一点。盾面反光里，那六个字像被挡下来，又被送回去，送回投影的金线框。

“名字不是项。”白昼说，“项能划掉。人划掉会空。空不该再被你们拿去填。”

潮汐把陈空手里那包白屑轻轻托住，怕他捏碎。她的手指凉，凉过纸边。

“叫着的，还要喝水。”她说，“水不算进你的冬夜。可没有水，冬夜里的人也活不成。你的算术漏了碗。”

影缚者笑。这一次不太像说谎。

“锁也算过。”她说，“锁空契，勒死，归编，一项一项。算到最后发现勒不住。勒不住的东西进不了你的表，院长。你儿子那天放行一分钟，也进不了表。表会记过。记过的人还在走路。走路的人开始怀疑——你要不要现在就通知他，别让他看见孔？”

司衡的目光微微一凝。凝在“儿子”两个字上。随即散开。散开是训练。训练让私情不进演讲。

森语引路者抬手，掌心朝向那些还在转的齿。齿上的字被她看一眼，就像被从土里认出来。

“根会记年轮。”她轻声，“年轮不是数完就烧。空地让路，不是让路给灶。你把名字当柴，柴会把路堵住。堵住以后，城也没有明年。”

炉心卫士敲了敲自己的胸甲。一下。实的。她说了入队以后很少说的词：

“护炉。不护账。”

熔渣咒印用一句脏话给演讲收尾，脏话里夹着司衡画像在炉心夜里被她骂过的那一次。炉灰医师不骂。她只把小瓶举了举，瓶里的白屑轻轻撞玻璃。

“病例要有名。”她说，“没名我无法治。你让我治一座没名的城，我做不到。”

机房里一时只剩齿轮。齿轮还在咬。咬是机器的职责。职责听不懂六个字。听不懂也要被按在这六个字下面转。转得忽然滞涩——像有一格名字不肯碎。不肯碎的那一格被后面的齿硬挤。挤出一声很尖的金属叫。

陈空听着那声叫。叫让他想伸手。伸手去把那一格从齿间抠出来。抠出来他也不会契术。不会，仍想抠。冰刃用刀面拦住他的腕。拦住，低声：

“你说完了。说完就站后面。站后面不是逃。是让这句话活着。活着比你的手重要。手去抠，齿会连你一起算进去。”

他收回手。收回，把那包白屑重新叠好。叠好按进肋骨。肋骨下心跳一下一下。一下一下像在复读：不算。不算。不算。复读没有用。用处是让他自己先记住。记住了，齿轮再咬，他也不会把名字让成数。

司衡恢复了那张干净的脸。

“我听见了。”他说，“听见不等于同意。同意要看城。城在上面。上面的人需要亮。你们可以在下层把这句话说得很响。响过以后，仍要有人把空填上。没有人填，守核会自己找。自己找的时候，陈空，你的口袋里那些牌会先响。牌是你揭的。揭过的名，管都记得。记得就会来收。”

陈空把纸包收好。收好，点头。点头不是服。是他把威胁听进骨头里。骨头会怕。怕了仍站。站着的人才能把位置空出来。

“我填不了。”他说，“我空着。空着不是为了给你们当仓。空着是……她们要住。”

住。这个字比粮轻。轻的字在机房里走不远。走不远也留下。留下就像拾荒标记，矮，浅，刮一下会疼。

司衡似乎终于结束了这堂课。他抬手。抬手不是告别。告别不需要液压。液压从壁内醒来。醒来的声音像有人把整座炉的门同时关上，又同时打开。打开的不是路。是槽。

槽边的铁皮翻起。翻起以后，人从里面站出来。

不能叫人。

身是契灵的身。关节是齿轮的关节。面上没有五官，只有编号烙印，烙得深，深到像从出厂就没有被叫过别的。四肢能弯，弯的方向却像锁链教过。胸腔透明。透明里看得见一撮白屑在转，转一圈，驱动一步。

机械契灵。

一排。两排。从槽里、从齿后、从榜的倒影里，往外拔。拔出来的时候带着油。油滴在地上，甜。甜得让冰刃的刀发出一声极轻的响。刀也厌恶甜。

“残次回收体。”影缚者认货，认得很准，“锁库的亲戚。炉心的炉渣。榜上咬剩的渣再铸一遍。它们没有不愿意。没有愿意。连不愿意都被咬掉了。”

陈空的喉咙动了。纠正的冲动顶上来。顶上来的是编号。编号在它们脸上亮着。亮着，他就想说：她不叫这个。

可它们也许真的没有名字了。没有了，他还是不能叫编号。叫编号就是帮齿轮完成最后一咬。

“别用号。”他对自己人说，声音哑，却清楚，“没有号。只有……还在走的。”

“还在走的要打。”冰刃说。

“打。”白昼把盾沉低。

潮汐把水在指间绕成一线，线很细，细得能切油。影缚者的笑收回去一半，一半留着，留着好在开战时扔冷笑话。森语的叶在发间发抖。炉心卫士横步，把陈空再次隔到铁后。熔渣咒印活动手腕，脏话已经在舌面上排队。炉灰医师退半步，退的位置仍能接住烫伤。

投影里的司衡看着这乱的一队，看着陈空被护在中间，像看着一项无法入账的浪费。浪费让他失望。失望仍被他写成必要的演示。

“让你们看看。”他说，“没有名字的力，一样能护城。一样能把空契按进管。算术不需要她们愿意。”

机械契灵迈步。步齐。齐得可怕。齐步落在机房地上，地上的白屑跳起来，像一群被踩醒的碎字。

陈空站在白昼后面。手按着盾沿。他不会打。他能喊。喊名字。喊自己人的名字。让乱的人更像人。让齐的东西至少知道对面不是编制。

他开口。嗓子里那点回来的声音被他抓得很紧。

“冰刃。”

刀亮了。

投影没有灭。司衡还要看着结果。结果在他的表上应当是：机械契灵推进，空契就范，名字继续被咬。

齿轮为它们让路。让路的齿间，那根对着陈空额的空管口忽然亮了一下。亮得像催。催粮入仓。

陈空没有朝管口走。他朝自己人的名字走。名字在前面。前面是打。打是她们的。他只负责把位置空出来。

空出来的时候，他听见司衡很轻地说了一句，轻得像写在表的边注上：“名字，不能当粮吗。能。只是咬起来慢。慢的账，城也付得起。”边注没有人接。不接，边注仍会跟着他们往下。往下有更饿的嘴。嘴不听六个字。不听也要先被这六个字挡一挡。挡是门。门还没开。开是后话。后话以前，先让乱的人把齐的东西砍出缝。

第一排机械契灵抬手。手里没有刀。手本身是刀。刀刃上刻着被咬剩的半个字。半个字还在挣扎，挣扎着被挥下来。

白昼的盾迎上去。

一下。一下。像有人用铁勺敲糊了的锅。锅在响。粥还没糊完。人还没死完。

机房开战。
