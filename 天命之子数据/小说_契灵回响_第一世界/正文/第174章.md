# 第174章 老家

路到后来只剩一条。

一条是被风按倒的草指出来的。草全朝东偏南。东偏南的褐变成黑。黑的土里有钉孔。钉孔成排。成排像旧时押运契灵的车辙。车辙里偶尔有一截断链。断链不认冰刃的刀。认影缚者的靴。靴一近，断链就轻轻一响，像狗。

“别踢。”影缚者说，“踢了它会跟。跟到门口，门口会多一张笑脸。笑脸是铁的。铁的笑比我真。”

冰刃把要踢的那脚收回来。收回来仍骂：“你老家养链当狗。狗还编号吗。”

“编号。号很长。长到没人肯叫。不叫就只剩锁。”影缚者的声音又轻回去，轻得像把笑话含化了，“锁库会认我。认的方式是开门。开门不是欢迎客人。是欢迎工具回架。架上缺我这一号。缺了多年。多年的空，他们会用链填。”

陈空走在她右侧。右侧能看见她被布裹住的腕。腕上布条被风掀起一角。一角里皮肤是冷的。冷的人说话仍损。损着，步子却没有偏。不偏是她自己选的路。选的路通向认她的门。门会填。填之前，他把自己那句准备好。准备好的句子短。短才能钉。

“那我进去。”他说。

影缚者停。停得太突然，森语差点撞上她的肩。肩很薄。薄的肩在这种风里像一根会响的弦。弦响了一下。响的是笑。笑出来，像真的听见了世界上最好笑的事。

“门去锁库。”她说，“笑话。”

陈空等她笑完。笑完他仍站着。站着的意思是句子没有收回。收回浪费。浪费他怕。

“我进去。”他又说了一遍。一遍是钉子。钉子要钉两下才稳。“你认门。门也认你。认来认去，里面会把你当架上的东西。我空着。空着不当架。不当架的人进去，他们要关也得先过我。过我很容易。容易的关不牢。关不牢你们就能砍。”

冰刃看他。看他的眼神像看一块自己包过的刀口。“你这脑子。脑子里只有进去。进去就会当肉垫。当肉垫我砍你腿。”

“腿留下。人进去。”陈空说。

白昼把盾立在路中。立一下是让风分。分了，影缚者的头发不那么乱。不乱的人眼睛对上陈空。对上，她的笑浅下去。浅下去露出那层不好看。不好看仍在。在的上面她摇头。摇头很轻。轻的摇头比骂重。

“锁库吃空契。”她说。吃这个字她用得很小心。小心是不把粮仓两个字落到他眼睛里。落到，他会吐。吐完仍会进。她只要他进的时候还站得直。“吃的方式不一定是牙。是关。关了出不来。出不来你就不是门。是门板上的钉。钉死了，我们住哪儿。”

“住我这儿。”陈空指了指自己的额。额空。空在黑风里什么都没有。什么都没有所以什么都能住。“出不来也先住着。住着你们想办法。办法我会的不多。多的是你们。你们都会。”

潮汐把净水塞进他手里。塞的力道重。重是怕。“肩还没好完。虎口有牙印。牙印会在里面被当成契纹的亲戚。亲戚他们会利用。利用你别伸脖子。”

“我伸过。”陈空说。伸过是灌纹台。灌纹台他关了。关了仍空。“空着比较难利用。难利用他们会烦。烦了会出错。出错你们就有缝。”

森语听完，把一根还活的根从土里拨出来，拨到影缚者脚边。“根认她。也认空。空和她一起走，根会让。让不是保证出。保证出的话我现在说不了。说不了仍带路。带路到门口。门口的字你们自己看。”

影缚者蹲下去。蹲下去摸那截断链。摸的姿势亲。亲完她把链弹开。弹开像弹一只不要的手。“笑话还是笑话。门去锁库。锁库会把你量一量。量完发现锁不住。锁不住他们会换法。换法很难听。难听的时候你让我选。选是我的。不是你替我当好人。当好人会把我按回架上。架上的我很听话。听话的我不要。”

陈空点头。点头很慢。慢的是把“让她选”三个字按进骨头。骨头里已经有过一次：井下她问为什么不命令。他不会命令。不会命令的人进锁库仍不会。不会就是位置。位置给她。给她选。选完无论是砍是留是拆，他都在。在不是拥有。冰刃教过全场：他不拥有。

冰刃把刀横在肩上，听完这句“好”，骂得更轻了。轻的骂才是真的。“让她选。你在井下也这么说。说完全场恨你。恨你的人里有我。有我也还是你对。对的人最蠢。蠢着进。进了把脖子伸给她。伸给她可以。伸给锁库的狗不行。不行我砍。砍完你再站。”

白昼点头。点头给冰刃，也给陈空。“侧面我挡。正面她选。你在后面。后面不是罚。是位置。位置你空着，她才选得动。选得动才不是架上的工具。”

“好。”他说，“我进去。你选。我站着。”

影缚者抬头。头发滑开。滑开的脸上仍不好看。不好看里有一点别的。别的像被谁在刮痕上填了几粒芝麻。芝麻很小。小的她立刻用笑话盖住：“站着别鞠躬。别递鉴定书。鉴定书他们会当合格证。合格就把你按进仓。仓里没有糊粥。没有糊粥你会死。死了谁记名字。”

“你记。”陈空说。

她噎了一下。噎完骂他有病。骂得很轻。轻的骂被东风带走。带走的风里，地窟的门已经从坡下露出来。露出来的不是门板。是一口黑。黑上有字。字还看不清。看不清，森语已经把路指死。指死的方向没有岔。没有岔是老家的规矩。规矩：认的人，只有这一条。

白昼把残徽从内袋取出。取出，握着。握着走向那口黑。黑还远。远的她已经把束绳系到最紧。最紧是准备把削掉的那块重新钉回胸口。钉回不是给锁库看。给她自己看。自己看过挡过，看过孩子，看过一寸天。看过的人把盾擦净。擦净时对陈空说：“我挡侧面。侧面也是门。你仍在后面。后面三步。三步是昼锋画的。画过的可以改。改短不行。改短你会伸。”

冰刃把刀抽出来半寸。半寸够亮。“笑话我们进。进了谁先伸链，我先砍链。砍完再听她选。选慢了我骂。骂完仍等。等是看门的规矩。看门的现在有两扇。一扇是他。一扇是我的刀。刀也算门吗。算。算就别把我当编号。”

陈空把火柴按在口袋最里。最里贴着卷宗。卷宗里有被刮掉的名字。名字旁边，他空着。空着往坡下走。坡下那口黑越来越大。大得像要把裂口合上的那一寸重新撕开。撕开也不回头。回头浪费。浪费的风里，影缚者跟在他影子里，像从来没有离开过。

她低声说：“笑话成真了。成真的笑话会咬人。咬了别松口。松口是我的事。”

潮汐在坡上看了看他的左肩。看完把纱布的边塞进补丁里，塞平。“进去会黑。黑了你别用手摸壁。壁上的链会当同意。同意用嘴拒绝。拒绝用名字。名字你有。有就反复喊。喊到哑，我给你水。”

陈空应好。应完，地窟的门在坡下完整地张开。张开的缝里没有光。有字。字要走近才读得清。读得清之前，他先把肩上的带子勒紧。勒紧的疤在这种黑风里忽然热了一下。热得像一块补丁被某种更白的东西从里面照穿。照穿还早。早的是门。门在等空契。等的方式写在铁上。

影缚者在他影子里补了一句。补句只给他听见：“笑话我收回一半。一半仍是笑话。一半是真的。真的那一半，你进了别后悔。后悔也晚。晚了就站着。站着让我选。选完如果我勒你，你别先原谅。原谅会把我按回去。按回去的我很干净。干净的我不要。”

陈空没有说不后悔。不后悔轻。他只把背包往上颠了颠，颠实。实的人往坡下走。坡下的黑把门的牙张开。张开等他们。等的链已经开始响。响得很亲。亲的那一面她听得懂。听得懂仍跟。跟的不是回架。是把门一起带进老家。老家要认她。认她的时候，也得看见她旁边那块空。空着的人不鞠躬。不鞠躬的人把位置留着。留着让她选。
