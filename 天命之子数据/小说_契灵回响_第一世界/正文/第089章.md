# 第89章 中和

毒水先舔上潮汐的踝。

踝是白的。白被绿覆住，覆住就烫。烫不是火。火会跳。这烫是洗。洗过的皮肤会忘冷，忘疼，忘自己为什么要伸手。潮汐把潮契整条按进水里。按进去的不是治疗那种柔。柔给伤口。这是压。压一口井去对另一口井。井和井咬在一起，咬得渠面鼓起一条脊。脊上全是脏泡沫。泡沫里有编号碎屑，碎屑是金契院洗过的名。

她咳血。

血掉进绿里，绿吃血，吃得很香。香和台上那股不一样。台上的香是“你能保护”。绿的香是“你不必记得”。不必记得的人最好用。最好用的人最会当药库。

陈空踏进水线。水没过他的鞋洞。鞋洞灌进铁味和绿。绿咬他的茧。茧没有纹，纹洗不着，它就改咬肉。肉疼。疼他不管。他从背包里摸那支净水。净水是潮汐先前塞给他的。塞的时候说先拿着。拿着不是为了自己喝。喝会活。活不够。够的是她还站着。

“给你。”他把瓶口咬开。牙印在软木塞上。软木塞苦。苦完他把水倒。倒的手很稳。稳得不像刚刚吐过。吐过的人胃是空的。空着也要把水倒准。准在她唇边。唇边有血。血会被净水冲淡。冲淡不是治愈。是让她还有一口自己的潮。

潮汐的眼睛抬起来。青潮长发贴在颊上，颊白得像井壁。她看见瓶。看见他。看见水不是往他自己嘴里去。

“你……中了。”她说。说得很断。断是因为咳。“绿咬你的腿。你该先洗自己。”

“先你。”陈空说。两个字。钉子。

倒水的时候他腿上的白气爬到膝。爬的地方发麻，麻的里面发空，空得像有人把他记得的路抽走一截。抽走他仍认潮汐的脸。脸比路要紧。路可以再数。脸要是被洗成抽屉，抽屉里就只剩药。药库不当新娘。不当新娘的人更不能被洗成井。

冰刃在水线外踩得金线乱响。“你倒就倒。”她喊，“倒完滚回来！回来让她咳。咳在你肩上可以。咳在绿里不行。绿会喝血。喝血的水会变甜。甜了你又要听残响。”

水倒完。瓶空了。空瓶他还握着。握着像还想再倒。没有了。没有了他把空瓶塞回她手里。塞回去是还。还的意思是：水是你的。你的水给你。我空着。空着还能走。

冰刃在水线外骂。骂声被喷管的余嘶撕成一段一段：“蠢货！你腿在冒白气！白气是洗！洗到骨头你就连拾荒都不会！”

“我不会的本来就多。”陈空说。这句话不是俏皮。是账。账他算得清。清的账里有一条：潮汐咳血。咳血的人不能再把最后一口净水让给他。让过的人太多。太多会把人当成药库。药库不当新娘。不当新娘的人也不该再当井。

白昼不能离开盾。离开井壁会合拢。合拢会把所有人当料吞。她只能把声音送过来。声音稳，稳里有重：“潮汐，点名。点你自己的名。名在，洗不走。”

潮汐点头。点头时把陈空倒给她的净水含住。含住不是喝完。是把那点净按进潮契里当芯。芯一亮，渠面那条脊忽然规整了一点。规整不是编制。是潮自己认路。路向毒。毒被压下去一寸。一寸。一寸像三十步。步步都是血。

她咳。咳在陈空肩上。肩是疤。疤承受过披风，承受过药，此刻承受一口红。红渗进补丁。补丁来者不拒。

“对不起。”陈空说。对不起的是自己只会倒水。倒水不是术。术能把毒送回管里。他不会。

“不许道歉。”潮汐说。先把剩下那点潮按实，再解释。解释很短，“你倒得对。对的水比术听指挥。术会问编制。水只问谁更空。你空，所以你能让。让不是废。废的是舍不得倒的人。”

影缚者站在水线的影子里。影子不被绿洗。洗不着的东西最适合看。她看着陈空空掉的瓶子，看着他腿上冒出的白气，忽然低声：“门也会漏。漏的是自己。漏给别人。金契院不教这个。他们教灌。灌是把别人漏进来的风堵死。堵死就满。满了就能一拳碎石。碎石很好看。好看完屋里没人。”

陈空听不懂全部。全部太长。长的他只抓住一句：屋里没人。屋里没人的棚他见过。见过就怕。怕比香硬。硬的怕让他没有把空瓶对着自己的嘴。

他把潮汐往盾后扶的时候，自己的鞋洞里灌满绿。绿从洞里往外喷。喷在金线上，金线第一次真正脏了。脏了像废都。废都的金不肯脏。不肯脏的东西最会吃人。吃人的台还没灭。没灭就还有第二道轮。第二道轮会说：你已经倒过水了，可以奖一次满。满一次，她就不必再咳。

陈空把空瓶握出一声轻响。响是瓶底碰茧。茧裂着。裂着他问潮汐：“还认得我叫什么吗。”

潮汐看他。看的时间很短。短里绿还在翻。翻着她仍答：“陈空。空的空。不是编号。编号我不会喊。喊了你要纠正。纠正会停手。停手毒会先走。”

他点头。点头比什么术都稳。稳是因为名字还在。名字在，洗就还没赢。

毒水又翻上来。翻的是余浪。余浪打在他膝上。膝发麻。麻了他还把潮汐往白昼盾后扶。扶得很笨。笨手在她腰侧，腰侧凉。凉是她的。她的凉正在被洗热。热了就危险。危险的人要到盾后。盾后有位置。位置是白昼留的。

冰刃踏进水，只踏两步。两步够把细管最后那截喉挑开，让余毒改道进一条废渠。废渠是影缚者用影子挖的。挖得很浅。浅也够。够了冰刃就把陈空的领子拎起来，拎得他咳。咳出来还有吐过的腥。

“站后面。”她说。先骂后挡。挡是把人扔到自己刀后。“你倒完水就不是英雄。不是英雄就闭嘴。闭嘴看闸。闸要是回牙，你再去趴。趴之前不许把额凑过去。额一香你就会傻。傻了我会砍管。砍完砍你。”

陈空被扔在盾后。盾后有裂。裂里漏石粉。石粉落在他头发上，像一场干的雪。他抬起头。抬头看见轮心那颗金钉还在。还在就还有选择。选择在司衡的礼貌里，在残响的甜里，在他自己腿上那圈被洗出来的白气里。

白气说：你也可以亮。亮了就能把剩下的毒一拳打碎。打碎潮汐就不必再咳。

台还没灭。

台灭要关死总闸之后再锁台心。台心有第二道轮。第二道轮更小。更小写着：打开，灌纹；关上，台死。打开的人会变强。变强再救。救完再谈空不空。这是算术。算术很完整。完整得像司衡的额。

陈空的手在抖。抖不是因为毒。毒让他麻。抖是因为那道小轮就在盾缝里闪光。闪光像真正的恩赐。恩赐说：你已经吐了，已经倒了水，已经够废了。废完可以奖一次满。满一次，她们就能歇。

潮汐抓住他的手指。凉回来了一点。一点就够按住抖。

“选择。”她说。只这一个词。词不替他做。做是他自己的。她只把空瓶放回他掌心。空瓶碰茧。茧裂着。裂着还能握。

大厅的香又浓了。浓得像有人把粥熬到刚好。刚好的米粒完整。完整的人坐在椅上，一拳把石墙打穿。打穿的光里没有糊锅。没有补丁。没有锁弹开的空响。

陈空看了看空瓶。看了看潮汐唇边被净水冲淡的血。看了看白昼盾上那道裂。看了看冰刃刀柄上那圈被金浆浸透的丑布。

白昼把裂开的盾沿又咬进石缝。咬进时她只丢下一句：“去关。关不是打开。打开的字在轮右边。右边你不认。不认就向左。向左我会顶到你拧死。”

他站起来。腿麻。麻了也走向那道更小的轮。走的时候鞋洞里的绿往外滴。滴在金线上，金线脏了一点。脏了一点他才像还能住在这里。

影缚者跟在他影子里。跟的距离仍不像队友。不像的人低声：“选择很好看。好看不是让你演。演会把拒变成姿态。姿态金契院也会。他们姿态叫保护。你要是向右，保护就成了。成了你就有边。有边我就能锁。锁得上，我今晚就能交差。交差我该高兴。该高兴的事我现在不想。不想你自己知道该拧哪边。”
