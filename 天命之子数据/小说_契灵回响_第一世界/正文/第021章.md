# 第21章 潮气里的手

浊井上风处，雾是青的。

井栏圆，石上长着一层薄盐，盐被潮气濡湿，摸上去像冷汗。告示钉在栏侧，字还清楚：禁饮。禁饮两个字下面有人加了一行小字，小字被抠掉，只剩抓痕。

陈空靠着白昼，左肩一跳一跳。布是披风撕的，金线看不见了，血把那一层浅金吃成暗褐。他闻见井。井不是水味。是铁，是旧血，是有人把记忆泡得太久以后发出来的馊。

冰刃先停。刀横在身前。

“有人。”她说。

有。井栏下风那一小块相对干净的石坪上，一个拾荒的蜷着，嘴边吐白沫，白沫里有细碎的蓝。蓝不是好颜色。废都的人见过，叫井毒，叫记性发作，叫喝了不该喝的一口。

一个青潮长发的女人跪在他身侧。

她不慌。手很凉，按在拾荒者的后颈，另一手把一只浅碗送到唇边。碗里不是井水。是更清的，清得几乎没有味道的水。她让那人喝。喝不下就撬牙。动作熟练，冷淡，像在做一件做了太多次、已经不必赋予心情的事。

陈空看见她的手指。指节白，甲缘干净，干净得不像废都。袖口却湿了，湿到肘，说明她在这种地方跪过不止这一回。

“别靠近。”冰刃低声。

白昼把盾微侧，挡住陈空的左肩朝向井口的那一面。“她在救人。”

“救人的也会收税。”冰刃说。

青潮长发的女人头也没抬。她把拾荒者侧过来，让吐沫流走，又按后颈，按得位置极准。拾荒者抽搐两下，蓝沫变浅，呼吸从嘶变成哑，哑总比没有强。

井栏上有旧绳。绳浸盐，硬，像死掉的蛇。陈空的目光从绳上滑到女人手腕——腕上没有锁，没有金徽，只有一圈被水泡久了的浅白。浅白让冰刃更烦。烦的东西往往不是敌人，是还没定性的人。

陈空的脚自己往前。左肩一扯，痛，他仍走。白昼没拉他。拉了，他大概会道歉，然后还是走。泥在靴底吧唧，他这才意识到自己把步子走响了。响在井上风处，像把三个人的来处喊给潮听。

女人这才抬头。

眼睛不像井。井浑。她的眼睛清，清得发冷。视线先落在冰刃的刀上，再落在白昼的盾上，最后落在陈空左肩那团褐布。褐布还在渗。渗得很慢，很坚持，像一口不肯承认自己破了的锅。

她皱眉。

不是同情。是看见一道不该还在漏的口。

“坐下。”她说。声音不高，带着潮都那边的软，软下面是不容商量。

冰刃的刀尖抬起来：“你谁。”

“先让他坐下。”女人说，“矢伤。潮气会把伤口泡开。泡开了，你们的盾也挡不住他往下掉。”

陈空坐下。不是听她。是腿软。他想说谢谢，说出口的仍是：“他更急。”他下巴朝拾荒者一点。

“他过了最凶的一阵。”女人把碗搁下，碗底磕在石上，轻响，“你没有。你还在装。”

“没装。”陈空说。

“装。”她伸手。手凉，凉得像刚从水里拿出来。她没问他同不同意，先把白昼包扎的结松开一线，看里面。血色暗，创口窄而长，擦着肉走，没入骨。她点一下头，像给一份还过得去的卷子打钩。

“谁包的。”

“我。”白昼说。

“布太粗。力道对。”女人从袖里取出更细的纱，纱是潮都的织法，边不散。她用净水冲陈空的肩。水一浇，痛从热变成亮。陈空的手指抠住石缝，抠得指节发白，仍没叫。

女人看他一眼。那一眼里有短暂的诧异，随即被熟练盖住。

“叫出来比较好。”她说，“不叫，气会堵在伤里。”

“叫过了。”陈空说，“她叫的。”

冰刃“啧”了一声，把刀横得更低，像恨这句话把她卖了。

拾荒者在旁边哼。女人分出一只手，又把水送到那人唇边。她做两件事的时候并不手忙脚乱。忙乱的是陈空。他想帮忙，手却不知道该伸到哪。伸到伤者那边，自己的血会滴进去。伸到她碗边，又像抢。

他只好把没血的那只手按在膝上，按成一只空碗。

空碗里什么都没有。他却觉得应该有。有布，有水，有一句能让伤口听话的话。他都没有。他只有自己的肩，肩还在漏，漏得没有规矩。

冰刃站在他斜前方，不挡女人的手，挡女人身后那条通往井口的缝。缝里往上翻铁味。铁味一浓，她的刀就更平。

“你若把井水灌他，”冰刃说，“我先灌你。”

“我灌过很多人。”女人头也不抬，“灌完他们会喊别人的名字。喊完死。我不喜欢死人在我手里还占着名字。”

白昼把撕剩的披风短角又往他背上掖了掖。掖的时候她看着潮汐的手，看着那双手如何把血和泥分开。分开得干净。干净让她想起教廷的水盆。水盆也干净。干净的地方不一定肯救人。

“时辰还早。”白昼忽然说，像报时，又像把这句话当成通行证，“她若要害，不必跪着害。”

冰刃不信通行证。她信刀。刀仍在。

“你是……井上的？”他问。

“路过。”女人说。

冰刃冷笑：“潮都的人路过废都的井？路过得挺准时。”

女人不解释。她把新纱缠上陈空左肩，缠得比白昼更贴，贴得他几乎能听见布和肉之间那一层水的声音。她的手指偶尔碰到他的锁骨，凉。陈空缩了一下。她当没看见。

井里忽然涌起一股更重的潮。潮声拍栏，盐粒从石上震下来，像细雪。白昼把盾立在上风，挡开那股直往伤口钻的湿。

“井水是记忆。”白昼说，不像问，“你用的不是井水。”

“净水。”女人说，“井水能救人，也能把人救进别人的死里。我懒得进去捞。”

陈空听懂了一半。一半已经够他害怕。他看着自己的肩，肩被包成一个干净的、属于别人的形状。白昼的披风布被她叠好，放还到他手里。他还想还给白昼。白昼摇头。

“垫着。别让潮再咬。”

拾荒者睁开一条眼。眼里没有神，只有怕。他看见金徽不在，看见刀，看见盾，看见陈空那张瘦脸，忽然抓住陈空的裤脚，哑着喊：“师……兄……别扔我……”

陈空一僵。

他不是这人的师兄。拾荒行里叫师兄的人很多，乱叫，叫错了也能换一口粥。他仍把手按在那人脏手上，按住。

“不扔。”他说。

女人看着这一幕，手里的碗停了一停。停得很短。随即她把剩余的净水倒进拾荒者嘴里，动作重新冷淡。

“别承诺。”她说，“你这种人最爱承诺。承诺完，自己先死。”

“我没想死。”陈空说。

“逃奴都这么说。”

风从井口翻上来，把她青潮长发吹到陈空腕上。发梢湿，凉，像一小截不肯属于废都的水。

冰刃的刀发出一声极轻的响，是拇指推刀镡。

“你再说一遍。”冰刃说。

女人已经把纱尾勒死。她站起来，袖口的湿更深了。她看陈空，看他额上那块空白，看他左肩，看他身边那把刀和那面盾。

看完，她把两个字放得很准，像把药放在该放的位置。

“逃奴。”

两个字落下，像诊断书盖印。井潮恰好转了一圈。盐粒打在陈空脸上，细，凉，像被轻轻抽了一下。他没反驳。反驳要先承认自己懂。他不太懂。他只懂自己一直在走，走出错的门，走进对的雨，走到一口不让喝的井。

女人已经把碗洗过，洗的还是净水。洗完，她看了看自己的手，手仍凉。凉手在废都是少见的干净。干净让陈空忽然想把最后那件不存在的衬衫再让一次。让不出去。衬衫早变成冰刃肋下的褐布。

雾在井口转。青潮长发也在转。转完，她把两个字又用眼神说了一遍。

逃奴。像诊断。像标签。像一张还没贴上墙的通缉。陈空把这两个字放在舌尖，没吐，也没咽。放着。放着就会凉。凉了，肩上的纱还是热的。
