# 第476章 门开的风

风先到废都。

锈门上的字还在：有契者入，无契者拾。风从“无契者拾”下面那道小痕里穿过去，穿得像有人用手指摸过。拾荒棚的糊锅盖被掀开一寸。一寸香是焦的。阿棉在棚里打了个喷嚏。喷嚏完她抓着糖纸跑出门，糖纸被风扯直，扯成一面很小的旗。她抬头。抬头看见东边的天裂开一条不像裂的亮。亮不伤眼。亮像有人把门缝推开。

“空哥？”她问风。风不答。风只把她的脏手吹冷。冷手里糖还在。她把糖捏紧，转身去叫拾荒行还醒着的人：“井那边开门！不是金契院的门！”

拾荒行主事当年关过他们的门。门关了，糖还在。糖在的人把旧行里能走的都喊起来。喊起来的人有的怕。怕空契。怕风。怕金徽又来碾石板。阿棉把糖举过头顶，像举一面不像样的旗：“怕就带着糖。糖是空哥的。空哥的门开了会让人过。过了还能回来喝糊的。”

有人骂她小孩。骂完仍跟。跟的队伍从锈门“拾”的那一侧走出去。走出去时门上的字被风摸了一遍。摸完“无契者拾”四个字轻轻响。响不是裂。是像被人念过。

炉心的烟在同一阵风里甜了一下。甜是旧的，旧得像烧过的名字。名字没再进烟。抽契井的铁针垂着，垂成晾衣杆。有人把孩子的襁褓从井栏上抱走。抱走时风帮他们一把，把井口的灰吹净。炉芯旧址的门板还在。门板后老人咳。咳完说：暖回来了一点。一点不是火。是风不再往炉里吸人。

潮都的铃乱。乱里潮后站在宫墙。墙外是海。海里的潮比铃准。准的潮拍上石阶，拍成一句没有字的话。潮后把冠扶正。冠很重。重的冠沿风一过，轻了一钱。一钱让她皱眉。皱眉看井。宫内抽契井只剩水。水映出她的脸。脸很嫌。嫌完她仍下令开闸：让能走的人走。走去哪。走去风来的方向。方向是废都以东、天命井以上的那片原野。她自己不走。不走的人把一箱净水砸给侍卫：“送。别写宫礼。写汤。”

侍卫问：冠呢。潮后看自己头上的冠。冠还在。在的冠曾经砸给女儿。女儿把冠给一个废材当碗。当碗的荒唐她骂过。骂过仍把汤舀进去。舀进去的手此刻按在墙沿上。墙沿冷。冷她不进圈。不进圈也算到。到是母亲的到。母亲的到很远。远得刚好够女儿回头看见。

木野的根抬头。

真的抬头。根墙从土里拱一拱，拱成许多张没有五官的脸。脸向着井的方向。年轮在土下发过一寸芽的地方，芽被冬风打弯，打弯仍指向空地。空地很远。远的铁勺影还在故乡桩。桩边的勺不在，勺在陈空包里。林把勺影当成路标。路标上风过，过成一行绿：去。荆棘让开一条夜路。夜路不伤人。只羞那些还想把空契当肥料的旧神残部。残部退。退的时候听见风里有人说：他不是土，他是路。

猎手的旧部在林边停住。停住看风。看风里没有命令。没有命令他们便把箭壶口朝下。朝下是不射。不射的人分出一半去原野。去看空地会不会把自己盖成楼。盖成楼他们就走。不盖，他们就站外围。站外围也是林的一种。

光庭的白软了。软过一度之后又软半度。法鼓没人敲。昼律无冠，站在大审的空阶上。风把他的头发吹乱。乱了也不去扶。他听过二十五人作证。听过陈空念名字。念到阿棉，念到顾衡。此刻风把那些名字又送回来一遍，送成门缝里的光。光不刺。刺的法已经摘下。他抬脚。抬脚向东。身边有人问：裁判长去哪。他说：去看门开。开了，条例要让路。

空阶上有人把法冠捡起来。捡起来他摇头。摇头是头轻。头轻的人走路更快。更快才能在合鸣前站到圈外。圈外不审。审过了。过了是听。

暗渊的阶上，被删的名亮了一层。一层很淡，淡得像呵气。呵气里夜刃的同类抬起头。影壁那样的墙转过面。低语在渊厅里自行走，走向出口。无名社的神龛空着。空着的龛被风灌满。灌满不是请人躺。是请人起。起的人把暗冠的碎片踢开，踢开去看门。门在很远的井上。井上有一个废材。废材空着。空着所以风能穿。

渊城里有人把躺了一小时的席卷起来。卷起来走路。走路的人互相叫名字。叫得出的亮。叫不出的先走。先走也能到原野。原野上的门缝不收躺着的人。不收是陈空教过的：可以废，不能躺。风把这句送回去。送回去有人骂。骂完仍走。

风穿到天命井原野时，陈空正被吹得睁不开眼。

他先是听见五属的声音，后才意识到自己仍站在井口。井口圆。圆被风灌成一条管子。管子不抽。管子过。过的东西里有阿棉的喷嚏，有潮后的铃，有根抬头的闷响，有法鼓空着的那一拍，有暗渊名阶上呵气的亮。他不会全知。全知是神的。神的座塌了。他只是空，空被这些声音路过。路过时他按住口袋。口袋里渣不亮。不亮他才没被风吹成另一个太阳。

他的围巾往后飞。影缚者按住他的领。按住的时候她自己也偏了偏身，像被什么从暗渊那边叫了一声。她没回头。“同类在来。”她说，“来看门，不来当锁。”

陈空的额发打在眼睛上。他空着。空被风灌。灌不是填。是过。过的时候他听见五属的声音叠在一起，叠得像合鸣的前奏。前奏里没有他的招。他本来就不会招。他只负责把位置空出来。位置此刻像一条走廊。走廊两端：一头是碎掉的太阳，一头是还没写上的约。

冰刃抓住他的手腕。抓住虎口牙印。牙印疼。疼让他不飘。

“别被风拽走。”冰刃说，“你要是飞起来，我就砍你的腿。砍完你还能空，不能飘。”

“我不飞。”陈空说，“我恐高。爬梯子都慢。风再大也慢。”

白昼在风里把盾横过来。横过来挡的不是敌，是要把陈空的人按在地上。潮汐的头发青潮一线，一线抽到他脸上，抽得很柔。森语闭着眼，听根在远方抬头的声音，听完点头：“集。他们会集。”

昼锋的干粮袋被风掀开，咸的碎屑打在陈空唇上。他舔一口。咸。咸得像还活着。晨星歌者在风里哼了一声。哼不是歌。是定音。定音太早，被冰刃瞪回去。瞪回去她便只哼给自己听。哼的是广场那一个“不”。不字被风放大，放大到原野，放大到五属，放大到所有抬头的契灵耳朵里。

司衡的编制营帐绳全断。帐倒。金徽滚。滚到陈空脚边。陈空弯腰捡起来。捡起来拍灰。拍完递给迎面跑来的文书。文书不敢接。陈空把徽放在他掌心：“还给你们。这不是我的。”

文书的手抖。抖的风更大。更大的风里顾衡走路。走路的人被吹得一个趔趄，趔趄仍走。走向陈空。走向那块空额。空额不亮。不亮的门缝已经够全世界把脸转过来。

陈空怕。怕还没说出口。怕先变成他按口袋的动作。口袋里渣不亮。不亮他才敢站。

原野的草全向他倒。倒成一条指向井口的路。路上还没有人影。人影在风后面。风后面是集。

他张了张嘴。嘴被风灌。灌出的不是契术。是一句很轻的：

“来了就……别叫编号。叫名字。”

风把这句话带走。带走像通知。通知第一世界：门缝开了。开了，人会来。来了，要集。集之前先把编号放下。放下才能进风。
