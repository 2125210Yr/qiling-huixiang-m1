## 分辨率

**新图完胜。**

旧帧是 GIF 抽帧再压成 JPEG：抖点、色带、边缘发糊。脸大约 40 px，眼睛 6–8 px，脚链 1–2 px。`eyewhite` / `iris` / `lash` / `mouth_*` / `anklet` 在这个密度下切出来就是色块，进 Cubism 网格会糊死。

新图约 **5.8× 像素、人像约 2.4× 高**。眼睛 12–16 px，脚链是一根能单独成层的金线，开衩金边和旗袍暗纹也读得出来。1280×720 对出货纹理仍偏紧，但已经是能切 35 槽、能补隐面的密度；546×292 不是。

预览画布是 16:9。旧帧塞进去会略裁或空边；新图比例对齐。

## 肢体分离

**新图更好切，但和现有绑定左右相反。**

两边都是「单腿高抬 + 插腰 + 高开衩」，空气都够，抬腿没有焊在裙子上。

| 部位 | 旧 GIF | 新生成 |
|---|---|---|
| 抬腿 vs 躯干 | 空隙大，但抖点和暗红墙吃掉轮廓 | 空隙大，腿缘干净，髋缝是明确的阴影 |
| 抬腿 vs 站腿 | 不重叠 | 不重叠 |
| 插腰手 vs 腰 | 手嵌在腰侧，暗红里分界弱 | 手、前臂、腰线分开，袖与腰没有焊死 |
| 下垂臂 vs 抬腿 | 同侧靠近，GIF 里手和脚发糊 | 同侧但有空隙，手、小腿能分开选 |
| 头发 vs 抬腿 | 短发不挡腿 | 长发全部飘向对面，**完全不挡抬腿** |
| 开衩片 vs 大腿 | 皮肤和红裙对比够，边缘毛 | 开衩是干净的金/红边，大腿整段可读 |
| 脚链 | 几个脏像素 | 独立细金线，能做 `anklet` |
| 角 | 有，但只有几个像素 | **没有**（切层表里的 `horn_l` / `horn_r` 对不上） |
| 抠像 | 黑发/暗裙/暗红墙，值接近 | 近黑空洞好抠身子；**黑发贴近黑底仍然难抠** |

新图对 `leg_raise_thigh` / `calf` / `foot_raise` / `arm_*_hip` / `dress_slit_panel` 更友好。旧图的优势只剩：构图已经对准当前 UV / `layer_plan.json` 轴点，以及切层表需要的双角还在。

新图的两个切层风险：

1. **左右对调。** `pose_lock.json` 是 `raisedLeg: R`、`supportLeg: L`，轴点也按「抬腿在画面左」。新图是镜像。直接换静帧，预览会把抬腿弹簧打在空背景上，头发弹簧打在抬起的腿上。
2. **右臂在画面里。** 锁姿势写明禁止 `hanging_arm_as_rest`。新图右臂很清楚，若坚持锁，要裁掉或改成「不入 rest」；若留下，切层表还少一条下垂臂。

## 补画（underpaint）

对照 `psd_cut_plan.md` / `textures/layer-manifest.json` 的必补项。

| 必补 | 旧 GIF | 新生成 |
|---|---|---|
| 刘海后头皮、前发后额头 | 刘海短，但像素脏，只能猜 | 发往后梳，额和发际线清楚；长发改盖后肩/背，补的是一大块可读的背发底 |
| 领口内脖子 | 高领埋在暗部，几像素 | 旗袍领 + 金边清楚，能补一截颈柱 |
| 开衩内大腿 | 露出多，但是脏边 | 整段大腿清楚，补开衩后侧有依据 |
| 眼白、口腔（比静帧更开） | 眼睛/嘴几乎是点，补等于重画 | 有虹膜高光和嘴形，仍须扩开口腔，但有脸可跟 |
| 抬腿髋缝 | 有影子，GIF 糊 | 开衩顶到髋，阴影可读 |
| 站腿裙底 | 裙子紧，髋形隐约 | 裙子更不透明、更长，裙下髋要多编一点，但比例清楚 |
| 胸/衣身遮挡、袖内肩 | 暗、糊 | 盘扣、胸形、无袖肩线清楚 |

**补画也是新图更好。** 旧帧不是「隐面少」，是隐面信息不够，眼白和口腔只能凭空造。新图隐面面积（长发后背、裙下站髋）更大，但每一处都有邻近像素可跟。

两边都解决不了的：黑发贴近黑底，后发轮廓仍要手修。新图发量更大，`back_hair` / `side_hair_*` 工作量更高，但这是可切，不是不可切。

## 预览该用哪张

**切层和下一版预览：用新生成的 1280×720。**

分辨率、肢体空隙、补画依据三项都是新图。`preview/` 画幅也是 16:9，新图对得上。旧 GIF 只适合当姿势备忘，不适合当导入级静帧。

**不要把新图直接拷成现在的 `preview/still.jpg`。** 网格 UV、`layers/pivots.json`、`layer_plan.json` 都是按旧 GIF「抬腿在左、坠发在右」标的。硬换会绑错部位。

要用新图当预览静帧，先做：

1. 按新构图重标抬腿 / 插腰 / 头发 / 胸 / 开衩轴点（抬腿改到画面右侧）。
2. 决定角：补画双角，或从切层表拿掉 `horn_l` / `horn_r`。
3. 决定右臂：裁掉以符合 `pose_lock`，或加下垂臂层并改锁。
4. 再复制为 `preview/still.jpg`（或改预览读 png），重出 `layers/*.png` 代理。

只想今天打开现有网格预览、不改绑定：继续用 `reference.jpg` → `preview/still.jpg`。那是权宜，不是更好的切图。
