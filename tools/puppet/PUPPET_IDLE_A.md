# Puppet 待机 A

点胸夹紧走 B（另画穿衣关键帧）。A 只用这一张静帧，做惯性待机。

## 胸（写进 A 的幅度）

偏明显的惯性，不是气球、不是挤乳沟。

- 左右两团绕附着点旋转，外下侧重，口子/腰腹肩钉住
- 待机：弹簧跟踪慢摆目标，约 **±2.2px 量级的角位移**（目标位 0.0022，上限 0.006）
- 点胸：只 `TapChest`，被点一侧冲量更大，同一套弹簧叠加，峰值大约是待机的 2～3 倍
- 不用缩放、不用往中线挤、不读 `SqueezeLeft/Right`、不转肩骨

渲染只读 `ChestLeft` / `ChestRight` 做 `RotZ`。垂直位移保持在约 2px 内，避免呼吸膨胀。

## 点击

| 区域 | A |
|---|---|
| 胸 | 只 `TapChest` |
| 脸 | 看 + 眨眼 |
| 腿 | 抬右腿 |

`StartClasp` / `ArmClosure` 留在 `PuppetMotion` 给 B，A 的 `Punch` / `CloseArms` / 骨骼 / 网格都不调用、不读取。

## 其余保留

眨眼、头发弹簧、重心换、腕/踝微动、右腿 IK。袖子保持原画姿势。
