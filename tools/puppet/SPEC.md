# 分层立绘输入规范（standee_front）

画布 **1024×1536**，2:3，角色脚底靠近画布底、头必须在框内。PNG 必须是 **RGBA**，透明处 alpha=0。

胸口画在 `body` 上：**禁止挖胸洞、禁止 `bust.png`。** 头发 / 头 / 手 / 脚 / 武器若要单独动，必须从 `body` 拿走同一份像素（互斥着色）。静止时所有槽 transform 必须是单位矩阵，叠回去应还原静帧。

## 文件名（小写）

| 文件 | 必选 | 内容 |
|---|---|---|
| `body.png` | 是 | 身体+衣服，胸口画在身上。有 `head` 时脸只在 head 上 |
| `hair_back.png` | 否 | 脑后发，可与身体重叠 |
| `hair_front.png` | 否 | 刘海 |
| `hair_side.png` | 否 | 侧发 |
| `head.png` | 否 | 仅头+颈（同一张静帧裁出，才能真转头） |
| `mouth_0.png` | 否 | 闭嘴（从静帧嘴部裁） |
| `mouth_1.png` | 否 | 半开 |
| `mouth_2.png` | 否 | 张开 |
| `hand_r.png` | 否 | 右手，同一姿势 |
| `hand_l.png` | 否 | 左手，同一姿势 |
| `foot_r.png` | 否 | 右脚，同一姿势 |
| `foot_l.png` | 否 | 左脚，同一姿势 |
| `sword.png` | 否 | 武器叠层 |
| `landmarks.json` | 否 | `head`/`chest`/`hand_r`/`hand_l`/`foot_r`/`foot_l` 为 `[u,v]`，原点左下 0..1 |

禁止：`bust.png` 当独立胸图层、身体挖胸洞、把另一套姿势的手脚贴上来。

`body.png` 与 `hair_*` / `head` 必须互斥着色：同一份像素只画在一层，不能两层各画一份再错位叠。

## 锚点经验范围（1024×1536）

- `chest`：胸腔中心，大约 u 0.45–0.58，v 0.62–0.76
- `head`：颅底/颈根，大约 u 0.48–0.58，v 0.78–0.88
- `hand_r`：右腕/握持，大约 u 0.38–0.48，v 0.50–0.58
- `foot_r` / `foot_l`：踝，大约 u 0.42–0.58，v 0.12–0.26
