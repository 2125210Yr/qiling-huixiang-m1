# Puppet 单图蒙皮修复 v0.1.1

范围：修正 C001 当前单张立绘的基础变形，不代表完成分层 Live2D。

- SmoothStep 的输入先做区间归一化，修复椭圆负权重及关节边缘跳变。
- 打包权重过滤负数与非有限值；保留四个主要影响后归一化。
- 头部权重的矩形硬边改为平滑过渡。
- 点击采用衰减弹簧，重复点击只增加速度，不重置当前位置。
- 胸部轻微呼吸的骨骼二维缩放保持面积；降低原有局部大幅旋转。
- 单图手腕与脚踝保持静止，避免武器与邻近发丝被错误带动。

验证：
- tools/puppet/test-rig.ps1：10 项回归检查通过，直接提取当前源文件函数，使用本机 Unity 6000.3.23f1 的真实数学程序集。原代码有 6 项失败。
- dotnet build client/Resonance.App.csproj：0 错误，24 个既有未赋值/未使用字段警告。
- Unity 6000.3.23f1 batchmode，PuppetRigVerification.Run：C001 加载成功；121 个姿态无三角形翻折；最小面积比 0.9102986；输出三张实际渲染图。
- 预览和日志在 codex专区/puppet-rig-fix。原脚本备份 PuppetRig.before.cs 保留于该目录。

限制：这里只采样了轻微待机与衰减姿态，未验收连续点击的完整 UI 流程。当前 puppet.json 仅配置 body；独立发丝、眨眼和转头透视并未实现。骨骼局部面积保持不等于整个蒙皮体积被严格保持。已打开的独立游戏 EXE 不会随源码修改自动更新，需要重新构建；Unity 编辑器重新运行会使用新脚本。
